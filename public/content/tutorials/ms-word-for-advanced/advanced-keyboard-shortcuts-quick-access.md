# Keyboard Shortcuts & Quick Access

## Power-User Mastery: Custom Shortcuts & QAT Portability

Power users do not adapt to Word; they adapt Word to their workflow. Microsoft Word allows you to remap any keyboard shortcut, build custom Ribbon tabs containing only your top 20 favorite tools, and export your setup across multiple computers.

### 1. Remapping Any Command to a Custom Hotkey

If you frequently insert tables, why click through menus? You can create your own shortcut:
1. Navigate to **File > Options > Customize Ribbon**.
2. At the bottom-left, click **Keyboard shortcuts: Customize...**
3. In the Categories box, select **Insert Tab**.
4. In the Commands box, select **TableInsert**.
5. Click inside **Press new shortcut key**.
6. Press your preferred key combo: e.g. `Alt + T`.
7. Notice *Currently assigned to: [unassigned]*.
8. In *Save changes in*, select **Normal.dotm** (to work across all files).
9. Click **Assign**, then click **Close**.
10. *Result*: Now pressing `Alt + T` anywhere in Word instantly opens the Insert Table dialog box!

### 2. Building a Custom Ribbon Tab

Tired of jumping back and forth between Home, Insert, Layout, and Review? Build your own personalized "My Workspace" tab:
1. Go to **File > Options > Customize Ribbon**.
2. Click **New Tab** beneath the right-hand column.
3. Rename the tab to `⭐ Power Tools`.
4. Rename the default group to `Favorites`.
5. From the left column (set to *All Commands*), add your top tools:
   - *Table*, *Track Changes*, *Format Painter*, *Insert Footnote*, *Watermark*, *Mail Merge*, *Export PDF*.
6. Click **OK**.
7. You now have your own bespoke Ribbon tab containing everything you need in one screen!

### 3. Exporting & Importing Your Customizations

When moving to a new office laptop or setting up a colleague's computer:
1. Go to **File > Options > Quick Access Toolbar** (or Customize Ribbon).
2. At the bottom-right, click **Import/Export**.
3. Select **Export all customizations**.
4. Save the `Word Customizations.exportedUI` file onto a USB drive or cloud drive.
5. On the new computer, open the same menu > select **Import customization file**.
6. All your custom buttons, QAT icons, and ribbon tabs appear instantly!

# Multiple Choice Questions

### 1. Where can you create your own custom Ribbon tab containing your favorite tools in MS Word?
A. View > Macros
B. File > Options > Customize Ribbon
C. Review > Protect
D. Home > Styles
**Answer:** B
**Explanation:** File > Options > Customize Ribbon allows creating new tabs and groups with custom commands.
---

### 2. What file format is generated when you export your Ribbon and Quick Access Toolbar customizations?
A. .exe
B. .exportedUI
C. .docx
D. .vba
**Answer:** B
**Explanation:** Word exports UI personalizations as a .exportedUI XML configuration file.
---

### 3. Can any native Word command be assigned a custom user-defined keyboard shortcut?
A. No, only macros can have shortcuts
B. Yes, through the Keyboard shortcuts: Customize dialog
C. Only in Word for Mac
D. Only with administrator privileges
**Answer:** B
**Explanation:** Word allows remapping virtually every built-in command to custom keyboard shortcuts.
---

### 4. Where should you save keyboard shortcut customizations if you want them available across all future documents?
A. Desktop
B. Normal.dotm
C. Temporary files
D. Windows Registry
**Answer:** B
**Explanation:** Saving in Normal.dotm ensures the shortcut is globally registered across all Word sessions.
---

### 5. What is the primary benefit of exporting your customizations via "Export all customizations"?
A. Backs up your document text
B. Allows transferring your custom Ribbon tabs and QAT buttons to a new computer in seconds
C. Compresses document images
D. Protects with a password
**Answer:** B
**Explanation:** Exporting customizations enables instant transfer of your customized interface across machines.
