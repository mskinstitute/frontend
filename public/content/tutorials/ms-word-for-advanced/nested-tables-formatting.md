# Nested Tables & Formatting

## Nested Tables: Advanced Multi-Tiered Layouts

A **nested table** is a table created inside the individual cell of another parent table. Power users leverage nested tables for sophisticated layouts like multi-part employment forms, complex medical intake charts, financial balance sheets, and catalog listings without breaking the parent grid alignment.

![Nested Tables and Advanced Formatting in Word](/images/tutorials/ms-word/tables-insert-format.svg)

### 1. Creating a Nested Table

1. Click inside the specific target cell of your existing parent table where you want the sub-table to live.
2. Navigate to **Insert > Table**.
3. Select the desired grid dimension (e.g. 2 columns by 3 rows) or click **Insert Table...**
4. The sub-table nests snugly inside the host cell. You can independently style its borders, column widths, font sizes, and background shading without affecting adjacent cells of the parent table!

### 2. Controlling Table Properties: Row Protection

When working with long tables, rows that split awkwardly across page breaks look unprofessional:
1. Highlight your table rows.
2. Navigate to **Layout** tab (under Table Tools) > click **Properties** (far left).
3. Switch to the **Row** tab:
   - **Uncheck: "Allow row to break across pages"**: If a row has extensive text, Word will keep the entire row together on the same page instead of cutting sentences in half across the bottom margin!
   - **Check: "Repeat as header row at the top of each page"**: Ensures multi-page tables retain headers on every subsequent page.

### 3. Custom Cell Margins (Cell Padding)

By default, text sits very close to table borders:
1. Go to **Layout > Cell Margins**.
2. Customize the default internal breathing room:
   - Top: `0.08 in`
   - Bottom: `0.08 in`
   - Left: `0.12 in`
   - Right: `0.12 in`
3. Check **Allow spacing between cells** if you want a modern tile/card look with physical gaps between cells!

# Multiple Choice Questions

### 1. What is a "nested table" in Microsoft Word?
A. A table saved in a hidden folder
B. A table inserted inside an individual cell of another table
C. A table converted into an image
D. A 3D perspective table
**Answer:** B
**Explanation:** A nested table is a child table situated inside the cell of a parent table.
---

### 2. Which checkbox in Table Properties prevents a table row from being awkwardly cut in half across a page break?
A. Keep with Next
B. Allow row to break across pages (uncheck)
C. Fixed Column Width
D. Repeat Header Rows
**Answer:** B
**Explanation:** Unchecking "Allow row to break across pages" ensures the entire row remains intact on one page.
---

### 3. Where can you adjust the internal blank padding between text and cell borders for an entire table?
A. Home > Font
B. Table Tools > Layout > Cell Margins
C. Design > Page Borders
D. Insert > Text Box
**Answer:** B
**Explanation:** Table Tools > Layout > Cell Margins controls top, bottom, left, and right internal cell padding.
---

### 4. Can a nested sub-table have completely different border colors and column widths than its parent table?
A. No, child tables inherit all parent properties
B. Yes, nested tables have independent formatting
C. Only if converted to Excel
D. Only on Windows, not Mac
**Answer:** B
**Explanation:** Nested tables operate with independent column widths, fills, and border rules.
---

### 5. What is the advantage of using nested tables over multiple floating text boxes for structured forms?
A. Smaller file size only
B. Structured tables flow naturally with text and maintain perfect alignment across revisions
C. Printers require nested tables
D. Text boxes cannot hold text
**Answer:** B
**Explanation:** Nested tables flow reliably with document text, eliminating the misalignment risks of floating shapes.
