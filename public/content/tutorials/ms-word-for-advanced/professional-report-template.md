# Professional Report Template

## Mini-Project 5: Building a Corporate Master Report Template

In this project, you will build an official corporate master template file (`.dotx`) that your entire department or organization can use to publish consistent, beautifully branded reports.

### Step 1: Establishing Document Geometry & Theme
1. Open a blank document. Set Margins to **Normal (1.0")**.
2. Go to **Design** tab > **Colors** > choose or build a custom palette:
   - Primary: Deep Navy (`#185ABD`)
   - Accent: Teal / Gold (`#0284C7`)
3. Set **Fonts**: Heading: *Segoe UI Semibold*, Body: *Calibri*.

### Step 2: The Designer Cover Page
1. Build a custom cover page with a vertical color bar shape along the left margin.
2. Insert dynamic fields:
   - `[DOCUMENT TITLE]` (24pt Bold Navy)
   - `[DOCUMENT SUBTITLE]` (14pt Muted Gray)
   - `[AUTHOR / DEPARTMENT]` (11pt Bold)
   - `[DATE]` (Date picker content control)
3. Insert a **Section Break (Next Page)** at the bottom.

### Step 3: Configuring Section 2 (TOC & Executive Summary)
1. Insert an **Automatic Table of Contents** on Page 2.
2. Uncheck **Link to Previous** in the Header & Footer of Section 2 so the cover page stays clean!
3. Insert footer: `Page X of Y` in Section 2, configured to **Start at Page 1**.

### Step 4: Standardizing Heading Styles
Modify the styles in the Styles Gallery:
- `Heading 1`: 18pt Bold Navy, `12pt` space before, `6pt` space after, check **Keep with next**.
- `Heading 2`: 14pt Bold Slate, `8pt` space before, `4pt` space after, check **Keep with next**.
- `Normal`: 11pt Calibri, 1.15 line spacing, `6pt` space after.

### Step 5: Pre-Formatted Callout Boxes
Insert a stylized sample callout box:
- Light blue background (`#EFF6FF`), left vertical border (3pt Dark Blue), italic body text.
- Save this callout into **Quick Parts > AutoText** as `report-callout` so authors can insert it with 1 click!

### Step 6: Saving as a Master Template (`.dotx`)
1. Press **F12** (Save As).
2. Set file type to **Word Template (*.dotx)**.
3. Save as `MSK_Corporate_Master_Report.dotx` in **Custom Office Templates**.
4. Test your creation: Go to **File > New > Personal** > double-click your template. A fresh, flawless report opens ready for authorship!

# Multiple Choice Questions

### 1. Why should a corporate report blueprint be saved as a .dotx template rather than a .docx document?
A. Templates load faster in RAM
B. Opening a template creates a new unsaved document instance, protecting master styles and logos from being overwritten
C. Templates cannot be deleted
D. Word only prints .dotx files
**Answer:** B
**Explanation:** Templates open as unsaved copies (Document1), preventing accidental overwriting of the master blueprint.
---

### 2. In which folder must a template be saved to appear automatically under File > New > Personal in Word?
A. C:\Windows
B. Documents\Custom Office Templates
C. Desktop
D. Downloads
**Answer:** B
**Explanation:** The "Custom Office Templates" folder under Documents is Word's indexed user template library.
---

### 3. Which break type isolates the cover page so that subsequent pages can start with Page Number 1?
A. Page Break
B. Section Break (Next Page)
C. Column Break
D. Soft Return
**Answer:** B
**Explanation:** A Section Break (Next Page) enables unlinking headers and footers and restarting page numbering at 1.
---

### 4. What paragraph rule should always be enabled on Heading 1 and Heading 2 styles in a corporate template?
A. Keep lines together
B. Keep with next
C. Suppress line numbers
D. Hyphenation
**Answer:** B
**Explanation:** "Keep with next" prevents headings from becoming separated from their following body paragraphs.
---

### 5. Where can you save reusable styled callout boxes and disclaimers for 1-click access across the company?
A. Font dialog
B. Quick Parts / AutoText Gallery
C. Spelling dictionary
D. Task Pane
**Answer:** B
**Explanation:** Saving items to Quick Parts / AutoText makes them instantly accessible via the F3 shortcut.
