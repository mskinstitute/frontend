# Assigning Macros to Buttons

## Assigning Macros to Buttons & Custom Shortcuts

Having to open the Developer menu to run a macro defeats the purpose of high-speed automation. The professional approach is assigning your macro to a dedicated **1-click Button** on the Quick Access Toolbar or a custom **Keyboard Shortcut**.

![Assigning Macros to Quick Access Buttons](/images/tutorials/ms-word/macros-vba-dialog.svg)

### 1. Adding a Macro Button to the Quick Access Toolbar

1. Click **File > Options** > select **Quick Access Toolbar** from the left panel.
2. In the **Choose commands from** dropdown, select **Macros**.
3. All your recorded macros appear in the list (e.g., `Normal.NewMacros.FormatDailyReport`).
4. Select your macro and click the **Add >>** button in the center.
5. With the macro highlighted in the right-hand column, click the **Modify...** button at the bottom:
   - **Display name**: Change the technical name to something clean like `Format Report`.
   - **Symbol**: Pick an intuitive visual icon (e.g. a blue smiley face, checkmark, document star, or lightning bolt).
6. Click **OK** twice.
7. Result: Your custom macro button now permanently resides on the top Quick Access Toolbar! Clicking it executes your automation in 1 click!

### 2. Assigning a Custom Keyboard Shortcut

If you prefer hotkeys:
1. Click **File > Options > Customize Ribbon**.
2. At the bottom-left next to *Keyboard shortcuts*, click **Customize...**
3. In the Categories box, scroll down and click **Macros**.
4. Select your target macro in the Macros box.
5. Click inside the **Press new shortcut key** input box.
6. Press your preferred combination (e.g. `Ctrl + Alt + Shift + R`).
7. Check *Current keys* to ensure it does not overwrite critical system commands.
8. Click **Assign**, then click **Close**.

# Multiple Choice Questions

### 1. Where can you place a 1-click icon button to trigger a frequently used macro instantly?
A. Status Bar
B. Quick Access Toolbar
C. Ruler
D. Task Manager
**Answer:** B
**Explanation:** The Quick Access Toolbar (QAT) can host custom macro buttons with personalized icons.
---

### 2. Under which menu in Word Options can you change the display name and icon symbol of a macro button?
A. Proofing
B. Modify button in Quick Access Toolbar settings
C. Language settings
D. Advanced Save
**Answer:** B
**Explanation:** The Modify button under QAT settings allows picking custom icons and clean display labels.
---

### 3. Which shortcut dialog allows assigning custom keyboard hotkeys to macros and ribbon commands?
A. File > Options > Customize Ribbon > Keyboard shortcuts: Customize
B. Ctrl + Alt + Delete
C. Review > Translate
D. View > Macros > Delete
**Answer:** A
**Explanation:** File > Options > Customize Ribbon > Keyboard shortcuts: Customize allows remapping all hotkeys.
---

### 4. What happens if you assign a hotkey like "Ctrl + C" to a macro?
A. Word displays an error and crashes
B. The macro overrides the standard Copy command
C. The shortcut is ignored
D. The file is deleted
**Answer:** B
**Explanation:** Word allows overriding built-in shortcuts, which is why checking "Currently assigned to" is critical.
---

### 5. Can a macro button placed on the Quick Access Toolbar be configured with a custom icon like a star or lightning bolt?
A. No, all macro buttons look like gray squares
B. Yes, from the built-in icon picker in the Modify dialog
C. Only if imported from Photoshop
D. Only on Mac
**Answer:** B
**Explanation:** Word includes an icon palette with dozens of colorful symbols for custom toolbar buttons.
