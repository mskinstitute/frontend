# Dashboard Layout: Tiled vs Floating, Containers & Alignment

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Tiled vs Floating Layouts
- **Tiled (Recommended for Responsiveness):** Visual elements snap cleanly into an automatic grid. Resizes gracefully across different screen resolutions.
- **Floating:** Visual elements sit at exact fixed pixel coordinates ($X, Y, W, H$). Can overlap each other.

---

## 2. Layout Containers: The Professional Secret
Never drop visuals randomly on a canvas. Structure your dashboard using **Layout Containers**:
- **Horizontal Container:** Arranges elements side-by-side from left to right.
- **Vertical Container:** Stacks elements on top of each other from top to bottom.
- **Outer Padding & Inner Padding:** Adds whitespace breathing room around cards.

# Multiple Choice Questions

### 1. What layout mode in Tableau snaps visual elements into a responsive, non-overlapping structured grid?
A. Tiled layout
B. Floating layout
C. Random mode
D. Absolute mode
**Answer:** A
**Explanation:** Tiled mode automatically arranges objects in a coordinated, non-overlapping grid structure.
---

### 2. What is the primary tool used by professional Tableau designers to control geometric alignment and spacing?
A. Horizontal and Vertical Layout Containers
B. Manual eye estimation
C. Using only one chart
D. Zoom slider
**Answer:** A
**Explanation:** Layout containers govern visual hierarchy, card grouping, and responsive distribution.
---

### 3. What does 'Distribute Contents Evenly' do inside a layout container?
A. Resizes all nested visual cards to have the exact same width or height automatically
B. Distributes data to users
C. Changes colors
D. Deletes empty spaces
**Answer:** A
**Explanation:** 'Distribute Contents Evenly' forces all children inside a container to take up equal proportions.
---

### 4. What is the difference between Inner Padding and Outer Padding in Tableau layout settings?
A. Outer padding adds whitespace outside the container border; Inner padding adds spacing inside the border around the chart
B. Inner padding is for text only
C. Outer padding costs memory
D. There is no difference
**Answer:** A
**Explanation:** Standard CSS-style padding separates outer boundaries from inner content.
---

### 5. What dashboard sizing mode ensures that a dashboard looks identical across all laptops and projectors without distorting?
A. Fixed Size (e.g. 1920x1080 or 1366x768)
B. Automatic
C. Range
D. Random
**Answer:** A
**Explanation:** Fixed Size locks aspect ratios and fonts, ensuring visual consistency across all client screens.
