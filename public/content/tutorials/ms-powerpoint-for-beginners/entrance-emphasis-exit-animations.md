# Object Animations: Entrance, Emphasis, Exit & Trigger Options

While transitions bridge separate slides, **Object Animations** bring life to elements residing on a single slide. When used with restraint, animations guide audience focus, reveal points progressively, and prevent viewers from reading ahead of the speaker.

![Animations & Animation Pane](/images/tutorials/ms-powerpoint/animations-and-pane.svg)

---

## The Four Animation Categories

On the **Animations** tab, click the gallery dropdown to explore the four distinct animation families, easily identified by their color coding:

### 1. Entrance Animations (Green Stars)
Controls how an object appears onto the slide canvas from a hidden state:
- **Appear**: Instantaneous reveal.
- **Fade**: Gentle dissolve into view (the most professional and versatile).
- **Fly In**: Slides into place from the bottom, left, right, or top (pair with short duration like 0.3s to avoid slow dragging).
- **Zoom / Wipe / Float In**: Clean, modern reveals for icons, cards, and diagrams.

### 2. Emphasis Animations (Yellow Stars)
Draws attention to an object that is *already visible* on the slide:
- **Pulse**: Gently enlarges and contracts.
- **Teeter**: Tilts back and forth subtly.
- **Spin**: Rotates 360 degrees.
- **Color Pulse / Fill Color**: Changes shape or font color to highlight a key takeaway or winning competitor during live discussion.

### 3. Exit Animations (Red Stars)
Controls how an object leaves or vanishes from the slide canvas:
- **Disappear**: Instantaneous removal.
- **Fade**: Dissolves into transparency.
- **Fly Out**: Exits off the screen perimeter.
- *Use Case*: Clearing previous data points or outdated comparison options to make room for new conclusions on the same slide.

### 4. Motion Paths (Blue Lines)
Moves an object from point A to point B along a visible path (Lines, Arcs, Turns, Shapes, or Custom freehand curves).

## Stacking Multiple Animations: "Add Animation" Warning!

> **The #1 Beginner Trap**: If an object already has a green Entrance animation, and you click a yellow Emphasis animation directly in the main ribbon gallery, PowerPoint **replaces** the original animation!
>
> **The Solution**: To assign a *second* animation to an object (e.g., Fade In, then Pulse, then Fade Out), you must click **Animations > Advanced Animation > Add Animation**!

---

## Controlling Animation Triggers & Sequences

In the **Timing** group on the Animations tab:
- **Start Settings**:
  - **On Click**: Animation fires only when the presenter clicks or presses Space/Arrow.
  - **With Previous**: Animation starts simultaneously at the exact same instant as the preceding animation or slide transition.
  - **After Previous**: Animation triggers automatically the moment the preceding animation finishes. Essential for chaining automated sequences without manual clicking!
- **Duration**: How many seconds the animation takes to run.
- **Delay**: Pauses for a specified number of seconds before starting (e.g., wait 0.5s after slide load before flying in).

## Animating Bulleted Lists Progressively

To keep your audience focused on what you are speaking about rather than reading ahead:
1. Select the bulleted text placeholder.
2. Apply **Animations > Fade**.
3. By default, PowerPoint assigns a numbered tag (`[1]`, `[2]`, `[3]`...) to each distinct bullet point.
4. During your slide show, pressing the Spacebar reveals Bullet 1. When you finish discussing it, pressing Spacebar reveals Bullet 2!

# Multiple Choice Questions

### 1. What color star icon represents Entrance animations in the PowerPoint Animations gallery?
A. Red
B. Green
C. Yellow
D. Blue
**Answer:** B
**Explanation:** Green star icons designate Entrance effects, yellow stars indicate Emphasis, red stars mark Exit effects, and blue lines represent Motion Paths.

---

### 2. Which button must you click if you want to assign a second animation to an object that already has an existing animation?
A. Change Animation
B. Add Animation
C. Duplicate Effect
D. Reorder Animation
**Answer:** B
**Explanation:** Clicking "Add Animation" appends an additional animation to the selected object, whereas choosing an effect from the main gallery replaces the current animation.

---

### 3. Which "Start" timing setting triggers an animation automatically the moment the preceding animation finishes playing, without requiring a mouse click?
A. On Click
B. With Previous
C. After Previous
D. Manual Trigger
**Answer:** C
**Explanation:** "After Previous" starts the animation automatically as soon as the prior animation completes, enabling continuous multi-step sequences.

---

### 4. What type of animation is best suited for drawing immediate attention to a statistic that is already visible on the slide?
A. Entrance (Green)
B. Emphasis (Yellow)
C. Exit (Red)
D. Slide Transition
**Answer:** B
**Explanation:** Emphasis animations (yellow stars, such as Pulse, Grow/Shrink, or Fill Color) animate elements that are already present on the canvas to draw audience eyes.

---

### 5. Why do professional speakers animate bulleted lists to appear one point at a time ("On Click")?
A. To prevent the audience from reading ahead and losing focus on what the speaker is currently explaining
B. Because PowerPoint slides can only hold one sentence at a time
C. To prevent file corruption
D. To make the slide show file smaller
**Answer:** A
**Explanation:** Revealing bullet points progressively synchronizes audience attention with the speaker's vocal delivery, preventing attendees from reading ahead.
