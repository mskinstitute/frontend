# Merging & Splitting Cells

## Merging & Splitting Cells in Tables

Complex tables (such as invoices, class timetables, and academic transcripts) require header rows that span across multiple columns, as well as sub-divided cells.

![Merging and Splitting Cells in MS Word](/images/tutorials/ms-word/tables-insert-format.svg)

### 1. Merging Cells

Merging combines two or more adjacent cells into a single continuous cell:
1. Drag your mouse to highlight the adjacent cells you want to unite.
2. Navigate to **Layout** tab (under Table Tools) > click **Merge Cells** in the Merge group.
3. *Alternative*: Right-click the highlighted cells and click **Merge Cells**.
4. Common use case: Creating a bold title banner across the top row of an itemized invoice.

### 2. Splitting Cells

Splitting divides one selected cell into multiple rows or columns:
1. Click inside the cell you wish to partition.
2. Go to **Layout** tab > click **Split Cells**.
3. In the popup dialog, specify:
   - **Number of columns**: e.g. 2 or 3
   - **Number of rows**: e.g. 1 or 2
4. Click **OK**; the cell divides into an internal sub-grid while preserving outer table alignment.

### 3. Splitting a Table (`Ctrl + Shift + Enter`)

If a table becomes too long or you need to insert narrative body text between two sections:
1. Place your cursor in the row that you want to become the first row of the *new second table*.
2. Press **Ctrl + Shift + Enter**.
3. Word splits the table into two separate tables and inserts an editable blank line between them!

### 4. Cell Alignment & Text Direction

Unlike standard text with 4 alignments, table cells support a **9-box alignment grid** on the **Layout** tab:
- Top Left, Top Center, Top Right
- Middle Left, Middle Center (Center), Middle Right
- Bottom Left, Bottom Center, Bottom Right

**Text Direction**:
- Clicking the **Text Direction** button rotates cell text by 90° clockwise, 270° clockwise, and back to horizontal. Essential for narrow column headers in large datasets.

# Multiple Choice Questions

### 1. What is the keyboard shortcut to split a single table into two separate tables at the cursor row?
A. Ctrl + Enter
B. Ctrl + Shift + Enter
C. Alt + Enter
D. Shift + F7
**Answer:** B
**Explanation:** Ctrl + Shift + Enter cleanly splits a table into two separate tables above the active row.
---

### 2. What is the action called when multiple selected cells are united into one single large cell?
A. Splitting
B. Grouping
C. Merging
D. Collapsing
**Answer:** C
**Explanation:** Merging combines two or more adjacent cells into a single unified cell.
---

### 3. How many distinct alignment positions are available in the table Layout Alignment grid?
A. 4 positions
B. 6 positions
C. 9 positions
D. 12 positions
**Answer:** C
**Explanation:** Word provides a 3x3 matrix of 9 alignments (Top, Middle, Bottom combined with Left, Center, Right).
---

### 4. Which tool on the Layout tab rotates text orientation inside a cell by 90 degrees?
A. Rotate Page
B. Text Direction
C. Orientation
D. Flip Text
**Answer:** B
**Explanation:** The Text Direction tool cycles cell text between horizontal and vertical orientations.
---

### 5. Can a single cell be split into both multiple rows and multiple columns simultaneously?
A. No, only columns can be split
B. No, only rows can be split
C. Yes, by specifying row and column counts in the Split Cells dialog
D. Only in Excel, not in Word
**Answer:** C
**Explanation:** The Split Cells dialog box allows you to specify both the number of columns and number of rows to create.
