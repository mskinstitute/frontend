# Essential Keyboard Shortcuts

## The MS Word Keyboard Productivity Guide

Relying solely on the mouse slows down drafting speed by up to 60%. Memorizing essential keyboard shortcuts allows your hands to stay on the keyboard, dramatically improving efficiency and focus.

### 1. Document Management & File Operations

| Action | Shortcut |
| :--- | :--- |
| **New Blank Document** | `Ctrl + N` |
| **Open Existing File** | `Ctrl + O` |
| **Save Document** | `Ctrl + S` |
| **Save As Dialog** | `F12` |
| **Print Document** | `Ctrl + P` |
| **Close Document** | `Ctrl + W` |
| **Exit Word** | `Alt + F4` |

### 2. Text Selection & Fast Navigation

- **Move Word by Word**: `Ctrl + Left / Right Arrow` (jumps whole words rather than single letters).
- **Jump to Top / Bottom of Document**: `Ctrl + Home` / `Ctrl + End`.
- **Select Word by Word**: `Ctrl + Shift + Left / Right Arrow`.
- **Select from Cursor to End of Line**: `Shift + End`.
- **Select from Cursor to Beginning of Line**: `Shift + Home`.
- **Select Entire Document**: `Ctrl + A`.

### 3. Deletion Shortcuts

- **Delete Character to Left**: `Backspace`
- **Delete Character to Right**: `Delete`
- **Delete Entire Word to Left**: `Ctrl + Backspace` (Massive time-saver!)
- **Delete Entire Word to Right**: `Ctrl + Delete`

### 4. Search & Replace

| Action | Shortcut |
| :--- | :--- |
| **Find (Open Navigation Pane)** | `Ctrl + F` |
| **Find and Replace Dialog** | `Ctrl + H` |
| **Go To (Jump to Page/Section)** | `Ctrl + G` |

### 5. Undo, Redo & Repeat

- **Undo Last Action**: `Ctrl + Z`
- **Redo Action**: `Ctrl + Y`
- **Repeat Last Action (`F4`)**: Performs the exact last formatting action again! (e.g. if you highlighted a row yellow, selecting another row and pressing **F4** instantly highlights it yellow!).

# Multiple Choice Questions

### 1. Which shortcut deletes an entire word to the LEFT of the cursor in one keystroke?
A. Backspace
B. Ctrl + Backspace
C. Delete
D. Shift + Backspace
**Answer:** B
**Explanation:** Ctrl + Backspace deletes the entire preceding word, speeding up text corrections.
---

### 2. What is the keyboard shortcut to jump directly to the very end of a document?
A. End
B. Ctrl + End
C. Alt + End
D. Page Down
**Answer:** B
**Explanation:** Ctrl + End jumps cursor focus directly to the last character of the document.
---

### 3. Which function key repeats your very last action or formatting choice in Word?
A. F2
B. F4
C. F7
D. F12
**Answer:** B
**Explanation:** F4 repeats the last formatting action or command executed in Word.
---

### 4. What is the keyboard shortcut to open the Find and Replace dialog box directly?
A. Ctrl + F
B. Ctrl + H
C. Ctrl + R
D. Alt + H
**Answer:** B
**Explanation:** Ctrl + H directly opens the Replace tab within the Find and Replace dialog box.
---

### 5. What is the shortcut to select all text and elements across the entire document?
A. Ctrl + S
B. Ctrl + A
C. Shift + A
D. Ctrl + Alt + A
**Answer:** B
**Explanation:** Ctrl + A (All) selects every element in the active document canvas.
