# Creating & Saving Documents

## Creating, Opening & Saving Documents

Document management is the foundation of working in Microsoft Word. Knowing how to create documents from scratch or templates, save files with proper naming conventions, and export to portable formats like PDF ensures your work remains safe and accessible.

### Creating a New Document

1. **Blank Document**:
   - Shortcut: Press **Ctrl + N** to instantly create a new blank document.
   - GUI Path: Click **File > New > Blank Document**.
2. **From Built-in Templates**:
   - MS Word provides hundreds of pre-designed templates for resumes, invoices, brochures, newsletters, and certificates.
   - GUI Path: Click **File > New**, type a search keyword (e.g., `Resume` or `Invoice`), select a template card, and click **Create**.

### Saving Your Work: Save vs. Save As

| Command | Shortcut | When to Use |
| :--- | :--- | :--- |
| **Save** | `Ctrl + S` | Updates existing changes to the currently opened file path. |
| **Save As** | `F12` or `Ctrl + Shift + S` | Saves the current document under a **new name**, in a **new folder**, or with a **different file type**. |

### Supported File Formats in MS Word

- **Word Document (`.docx`)**: The default modern XML-based document format introduced in Office 2007. It provides compact file size, crash resilience, and support for all modern formatting features.
- **Word 97-2003 Document (`.doc`)**: Legacy binary format maintained for backwards compatibility with older software.
- **PDF Document (`.pdf`)**: Portable Document Format preserves visual appearance across all operating systems and prevents accidental modifications by recipients.
  - To save as PDF: Navigate to **File > Export > Create PDF/XPS Document**, or choose **PDF (*.pdf)** from the Save As file type dropdown.
- **Plain Text (`.txt`)**: Strips all formatting, keeping only raw ASCII/Unicode text.

### AutoRecover & Backup Protection

Microsoft Word includes an automated safety net called **AutoRecover**:
- By default, Word automatically saves a snapshot of your document every **10 minutes** behind the scenes.
- If your computer suddenly loses power or crashes, the next time you launch Word, the **Document Recovery** task pane opens, allowing you to restore your unsaved edits.
- You can customize this interval by navigating to **File > Options > Save** and changing `Save AutoRecover information every X minutes` (e.g., 2 or 5 minutes for greater safety).

# Multiple Choice Questions

### 1. What is the default file extension for modern Microsoft Word documents?
A. .doc
B. .txt
C. .docx
D. .rtf
**Answer:** C
**Explanation:** Since Word 2007, .docx is the standard XML-based compressed file extension for Word files.
---

### 2. Which key is the dedicated keyboard shortcut to open the "Save As" dialog box in MS Word?
A. Ctrl + S
B. F12
C. F2
D. Ctrl + Alt + S
**Answer:** B
**Explanation:** Pressing the F12 function key directly opens the Save As dialog box to choose a new location, name, or format.
---

### 3. Which shortcut instantly creates a brand new blank Word document?
A. Ctrl + N
B. Ctrl + O
C. Ctrl + B
D. Ctrl + W
**Answer:** A
**Explanation:** Ctrl + N (New) immediately spawns a fresh blank document in a new window.
---

### 4. How can you convert an active Word document into a non-editable PDF file?
A. File > Print to Fax
B. File > Export > Create PDF/XPS
C. Home > Styles > PDF
D. Ctrl + Shift + P
**Answer:** B
**Explanation:** Navigating to File > Export > Create PDF/XPS exports the document directly into standard PDF format.
---

### 5. Where in Word settings can you configure how frequently AutoRecover saves backup copies?
A. Home > Options > Edit
B. File > Options > Save
C. Review > Proofing
D. Insert > Document Info
**Answer:** B
**Explanation:** In File > Options > Save, you can customize the AutoRecover snapshot interval and backup folder path.
