# Inserting Tables, Images, and Media on Slides (चित्र, टेबल और मीडिया जोड़ना)

Text-heavy slides cause audience fatigue (known in corporate training as *"Death by PowerPoint"*). Integrating visual assets—such as photographs, comparison tables, vector shapes, audio narrations, and video clips—transforms a dull lecture into an engaging visual experience.

---

## 1. Inserting Images and Photos (तस्वीरें जोड़ना)

- In **LibreOffice Impress**: Click **Insert menu $\implies$ Image**.
- Browse and select your image file (`.jpg`, `.png`, `.svg`).
- **Resizing Images Proportionally:**
  - Always click and drag from the **corner handles (कोने वाले हैंडल)** while holding down the **`Shift`** key!
  - Dragging from side handles will distort and stretch the human faces or logos!

---

## 2. Inserting Shapes and Smart Graphics

Shapes clarify processes, workflows, and hierarchies:
- Click the **Shapes toolbar** to insert:
  - **Rectangles, Circles, Stars, Banners**.
  - **Arrows (तीर):** Directs audience attention to key chart points.
  - **Flowchart symbols:** Process boxes, Decision diamonds.

---

## 3. Inserting Tables on Slides

To compare features (e.g. comparing RAM vs ROM):
- Click **Insert menu $\implies$ Table**.
- Select the number of columns and rows.
- Format the table with high-contrast alternating header colors.

---

## 4. Inserting Audio and Video Clips (ऑडियो और वीडियो)

Multimedia brings demonstrations to life:
- Click **Insert menu $\implies$ Audio or Video**.
- Select a media file (`.mp4`, `.mp3`, `.wav`).
- A media playback bar will appear at the bottom of the slide allowing you to set playback:
  - *Play automatically* when the slide appears.
  - *Play on click*.

# Multiple Choice Questions

### 1. Which menu in LibreOffice Impress is used to insert images, tables, shapes, and video clips?
A. File Menu
B. Insert Menu
C. Tools Menu
D. View Menu
**Answer:** B
**Explanation:** The Insert menu houses all commands for introducing external media, images, shapes, tables, audio, and video onto slides.

---

### 2. How should you resize an inserted image to prevent stretching or distorting its proportions?
A. Drag from the top border handle
B. Drag from the side border handle
C. Hold `Shift` and drag from a corner handle
D. Cut and paste the image
**Answer:** C
**Explanation:** Holding `Shift` while dragging a corner handle preserves the original aspect ratio (width-to-height proportion), preventing distortion.

---

### 3. Which multimedia file formats are commonly supported for embedding video inside presentation slides?
A. `.mp4`
B. `.txt`
C. `.odt`
D. `.csv`
**Answer:** A
**Explanation:** `.mp4` is the universal digital multimedia container format widely supported for slide video playback.

---

### 4. What is the visual consequence of dragging only the middle-side handle of a picture?
A. It crops the image
B. It stretches or squishes the image unnaturally, destroying aspect ratio
C. It deletes the image
D. It rotates the image 90 degrees
**Answer:** B
**Explanation:** Dragging side handles alters only width (or only height) independently, resulting in an unnatural, distorted image.

---

### 5. Can an inserted shape on a slide contain editable text inside it?
A. No, shapes cannot contain text
B. Yes, by double-clicking or right-clicking the shape and typing text
C. Only in word processors
D. Only if the shape is a circle
**Answer:** B
**Explanation:** Shapes in presentation software double as text containers; double-clicking any shape enables immediate text typing inside the shape boundaries.
