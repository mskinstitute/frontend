# Creating, Opening, Saving, and Printing Documents (दस्तावेज़ बनाना और प्रिंट करना)

Managing document lifecycle—creating new files, opening existing records, saving progress, exporting to PDF, and printing hard copies—is the most frequent daily routine in any computer office.

---

## 1. Creating and Opening Documents

- **Creating a New Blank Document:**
  - Click **File $\implies$ New $\implies$ Text Document**.
  - Shortcut: **`Ctrl + N`** (Both in Writer and Word).
- **Opening an Existing Saved Document:**
  - Click **File $\implies$ Open**.
  - Shortcut: **`Ctrl + O`**.
  - Browse your folders, select the target file, and click Open.

---

## 2. Saving Documents: "Save" vs "Save As"

Many beginners get confused between **Save** and **Save As**:

| Feature | Save (`Ctrl + S`) | Save As (`Ctrl + Shift + S`) |
| :--- | :--- | :--- |
| **Purpose** | Saves recent modifications to the **existing file** at its current location. | Saves a **new copy** of the file with a different name, file type, or location. |
| **Dialog Box** | Appears only the **very first time** to name the file; subsequently saves silently. | Always opens the Save As dialog box every single time. |
| **Shortcut** | **`Ctrl + S`** | **`Ctrl + Shift + S`** (Writer) / **`F12`** (Word) |

---

## 3. Exporting Directly to PDF (पीडीएफ बनाना)

In government offices and for online job applications, documents must be shared in PDF format so fonts and formatting cannot be tampered with.

- In **LibreOffice Writer**, you can export directly without installing extra software:
  - Click the **"Export Directly as PDF"** icon on the Standard Toolbar.
  - Or go to **File $\implies$ Export As $\implies$ Export as PDF**.

---

## 4. Print Preview and Printing Hard Copies

Before sending a document to a physical printer, always inspect **Print Preview (प्रिंट पूर्वावलोकन)** to verify margins, headers, and page breaks. This saves paper and ink!

### Print Preview Shortcuts (CCC Exam Alert!):
- In **LibreOffice Writer:** **`Ctrl + Shift + O`**
- In **Microsoft Word:** **`Ctrl + F2`**

### Printing the Document:
- Shortcut: **`Ctrl + P`**
- In the Print dialog box, you can choose:
  - **Printer Name:** Select your connected laser or inkjet printer.
  - **Print Range:**
    - **All:** Prints the entire document.
    - **Pages (e.g. 1-5, 8):** Prints only specified pages.
    - **Selection:** Prints only highlighted text.
  - **Number of Copies:** Number of duplicate prints needed.
  - **Collate (कोलेट):** If printing 3 copies of a 5-page document:
    - *Collate Checked:* Prints Page 1,2,3,4,5 then Page 1,2,3,4,5 then Page 1,2,3,4,5 (Neat sets ready for stapling!).
    - *Collate Unchecked:* Prints Page 1,1,1 then Page 2,2,2 then Page 3,3,3.

# Multiple Choice Questions

### 1. What is the keyboard shortcut for Print Preview in LibreOffice Writer?
A. `Ctrl + P`
B. `Ctrl + F2`
C. `Ctrl + Shift + O`
D. `Alt + P`
**Answer:** C
**Explanation:** In LibreOffice Writer, `Ctrl + Shift + O` toggles Print Preview on and off. In MS Word, `Ctrl + F2` is used.

---

### 2. Which keyboard shortcut is used to save a file with a new name or in a new location ("Save As") in LibreOffice Writer?
A. `Ctrl + S`
B. `Ctrl + Shift + S`
C. `F12`
D. `Alt + S`
**Answer:** B
**Explanation:** In LibreOffice Writer, the shortcut for "Save As" is `Ctrl + Shift + S`. In Microsoft Word, the standard shortcut for "Save As" is `F12`.

---

### 3. What is the universal keyboard shortcut to open the standard Print dialog box?
A. `Ctrl + Shift + P`
B. `Ctrl + P`
C. `Alt + P`
D. `F8`
**Answer:** B
**Explanation:** `Ctrl + P` is the universal keyboard shortcut across Windows, LibreOffice, MS Office, and web browsers to open the Print setup window.

---

### 4. What does checking the "Collate" option do when printing multiple copies of a multi-page document?
A. Compresses pages into a smaller font
B. Prints complete sequential sets (1, 2, 3...) rather than repeating each page (1, 1, 1...)
C. Prints in black-and-white only
D. Converts text into PDF
**Answer:** B
**Explanation:** The "Collate" setting groups multi-page printouts into complete ordered sets (e.g. Set 1: Pages 1-5; Set 2: Pages 1-5), making manual sorting unnecessary.

---

### 5. Which menu in LibreOffice Writer contains the command to export a document directly into PDF format?
A. Edit Menu
B. File Menu
C. Insert Menu
D. Tools Menu
**Answer:** B
**Explanation:** The File Menu houses all file-level persistence and transformation commands including New, Open, Save, Save As, and "Export As > Export as PDF".
