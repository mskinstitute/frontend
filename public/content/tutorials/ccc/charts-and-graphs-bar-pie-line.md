# Charts and Graphs (चार्ट और ग्राफ)

A picture is worth a thousand words. In business meetings, government presentations, and budget analysis, raw columns of numbers are difficult to digest. 

A **Chart** (or Graph) is a visual, graphical representation of spreadsheet data that reveals trends, patterns, comparisons, and proportions at a single glance.

---

## 1. Common Chart Types and When to Use Them

The NIELIT CCC exam regularly tests which chart type is best suited for specific data scenarios:

```text
+-----------------------+-----------------------------+-----------------------------+
| Chart Type            | Visual Layout               | Ideal Real-World Use Case   |
+-----------------------+-----------------------------+-----------------------------+
| Column / Bar Chart    | Vertical / Horizontal       | Comparing discrete items    |
| (कॉलम / बार चार्ट)    | rectangular bars            | (e.g. Sales across 5 cities)|
+-----------------------+-----------------------------+-----------------------------+
| Pie Chart             | Circular disc sliced into   | Showing percentage parts of |
| (पाई चार्ट)           | proportional wedges         | a 100% whole (e.g. Budget)  |
+-----------------------+-----------------------------+-----------------------------+
| Line Chart            | Data points connected by    | Tracking changes and trends |
| (लाइन चार्ट)          | continuous lines            | over TIME (e.g. Stock price)|
+-----------------------+-----------------------------+-----------------------------+
| Scatter (XY) Plot     | Isolated coordinate dots    | Scientific correlation      |
| (स्कैटर प्लॉट)        | across X and Y axes         | between two variables       |
+-----------------------+-----------------------------+-----------------------------+
```

## 2. Anatomy of a Chart (चार्ट के मुख्य घटक)

A complete chart consists of several standard anatomical elements:

1. **Chart Title (शीर्षक):** The main heading at the top explaining what data the chart portrays (e.g. *"Annual UP Wheat Production 2026"*).
2. **X-Axis (Horizontal / Category Axis):** Displays the categories being evaluated (e.g. *Months: Jan, Feb, Mar*).
3. **Y-Axis (Vertical / Value Axis):** Displays the numerical values and scale (e.g. *₹0 to ₹1,00,000*).
4. **Data Series:** The actual visual bars, slices, or lines representing data points.
5. **Legend (संकेत सूची):** A small key or color box identifying which color corresponds to which category (e.g. *Blue = 2025, Green = 2026*).
6. **Data Labels:** Exact numerical values displayed directly on top of individual bars or pie slices.
7. **Gridlines:** Subtle background horizontal/vertical lines helping the eye trace values across to the axes.

## 3. Inserting a Chart in LibreOffice Calc

1. Select the data table range including headers (e.g. `A1:B6`).
2. Click the **"Insert Chart"** icon on the Standard Toolbar.
3. Or go to **Insert menu $\implies$ Chart**.
4. The **Chart Wizard** will guide you through 4 simple steps:
   - *Step 1:* Choose Chart Type (Column, Bar, Pie, Line, Area, XY Scatter).
   - *Step 2:* Confirm Data Range.
   - *Step 3:* Configure Data Series.
   - *Step 4:* Enter Chart Elements (Title, Subtitle, X/Y Axis labels, Legend placement).
5. Click **Finish**. The chart is inserted as an interactive movable object on your sheet!

# Multiple Choice Questions

### 1. Which chart type is best suited for showing the percentage breakdown of a government budget totaling 100%?
A. Line Chart
B. Pie Chart
C. Scatter Plot
D. Radar Chart
**Answer:** B
**Explanation:** A Pie Chart represents proportions of a whole, where each wedge corresponds to a percentage of the 100% total, making it ideal for expenditure or budget breakdowns.

---

### 2. Which chart type is most effective for illustrating temperature changes and market trends over continuous time periods?
A. Pie Chart
B. Line Chart
C. Doughnut Chart
D. Bubble Chart
**Answer:** B
**Explanation:** Line Charts connect discrete sequential data points with continuous lines, making them the gold standard for visualizing time-series trends and trajectories.

---

### 3. What is the small box that explains the color codes and symbols used in a chart called?
A. Plot Area
B. Legend
C. Title Bar
D. Data Label
**Answer:** B
**Explanation:** The Legend is the key or index that explains what each specific color, bar pattern, or line represents in the chart.

---

### 4. Which menu in LibreOffice Calc contains the command to insert a Chart?
A. Data Menu
B. Insert Menu
C. Format Menu
D. Tools Menu
**Answer:** B
**Explanation:** Charts, images, shapes, headers, and media are inserted into the sheet via the **Insert** menu ("Insert > Chart").

---

### 5. In a standard 2D Column Chart, what does the horizontal (X) axis typically represent?
A. Numerical totals
B. Categories / Labels
C. Color palettes
D. Zoom percentage
**Answer:** B
**Explanation:** In standard column charts, the horizontal X-axis represents the independent categories (e.g. student names, months, or departments), while the vertical Y-axis displays numerical values.
