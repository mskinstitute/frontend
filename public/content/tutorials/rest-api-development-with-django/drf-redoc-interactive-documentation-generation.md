# Redoc Interactive Documentation Generation

While Swagger UI is renowned for interactive "Try it out" testing, **Redoc** provides a cleaner, highly readable, three-column layout inspired by modern developer documentation (such as Stripe and Twilio).

---

## 1. Redoc vs Swagger UI

| Feature | Swagger UI | Redoc |
| :--- | :--- | :--- |
| **Layout** | Single-column accordion list | Clean 3-column responsive layout (Navigation / Content / Code samples) |
| **Interactive "Try It Out"** | Built-in browser HTTP execution | View-only (or requires third-party plugins) |
| **Search & Filtering** | Basic string filter | Fast fuzzy search with deep linking |
| **Visual Polish** | Functional, utility-focused | Elegant, publication-ready for external developers |

In professional production architectures, exposing both `/api/docs/swagger/` (for internal testing) and `/api/docs/redoc/` (for external partners and client developers) is best practice.

---

## 2. Redoc Endpoint Configuration

Configuring Redoc with `drf-spectacular` is straightforward:

```python
# config/urls.py
from django.urls import path
from drf_spectacular.views import SpectacularAPIView, SpectacularRedocView

urlpatterns = [
    path('api/schema/', SpectacularAPIView.as_view(), name='schema'),
    path('api/docs/redoc/', SpectacularRedocView.as_view(url_name='schema'), name='redoc'),
]
```

---

## 3. Customizing Redoc Appearance and Metadata

You can customize the Redoc interface through `SPECTACULAR_SETTINGS` in `settings.py`:

```python
SPECTACULAR_SETTINGS = {
    'TITLE': 'MSK Institute Cloud API',
    'DESCRIPTION': '''
# Welcome to MSK Institute API

This API provides endpoints for authentication, course enrollment, real-time analytics, and billing.

## Authentication
All requests must include an `Authorization: Bearer <token>` header obtained from `/api/v1/auth/token/`.
    ''',
    'VERSION': '2.4.0',
    'REDOC_UI_SETTINGS': {
        'hideDownloadButton': False,
        'expandResponses': '200,201',
        'theme': {
            'colors': {
                'primary': {
                    'main': '#4F46E5',  # Indigo brand color
                }
            },
            'typography': {
                'fontFamily': 'Inter, sans-serif',
                'headings': {
                    'fontFamily': 'Poppins, sans-serif',
                }
            }
        }
    }
}
```

## Practice Quiz

### Q1: What layout style is characteristic of Redoc documentation?
- A) A single page raw JSON dump
- B) A responsive three-column layout with left navigation, center documentation, and right code samples/payloads
- C) A modal popup dialogue
- D) A command-line terminal emulator
**Answer:** B
**Explanation:** Redoc is renowned for its elegant three-column layout featuring a left table of contents, center endpoint documentation, and right request/response code samples.

### Q2: How does `SpectacularRedocView` obtain the API schema it displays?
- A) It inspects git commit history
- B) It points to the URL specified by `url_name='schema'` (which resolves `SpectacularAPIView`)
- C) It reads a static `.txt` file from the Django media folder
- D) It queries a third-party microservice
**Answer:** B
**Explanation:** `SpectacularRedocView.as_view(url_name='schema')` consumes the dynamic OpenAPI schema generated by the `SpectacularAPIView` endpoint.

### Q3: What is the key functional difference between Swagger UI and Redoc?
- A) Redoc supports PostgreSQL while Swagger only supports MySQL
- B) Swagger UI emphasizes interactive "Try it out" test execution, whereas Redoc emphasizes readability and developer documentation presentation
- C) Swagger UI cannot display HTTP status codes
- D) Redoc cannot display JSON schemas
**Answer:** B
**Explanation:** Swagger UI allows live requests directly inside the browser, whereas Redoc provides a sleek, publication-grade reading experience for public API consumers.

### Q4: Where are custom brand colors and fonts configured for Redoc in a DRF project?
- A) In `public/index.html`
- B) Inside `SPECTACULAR_SETTINGS['REDOC_UI_SETTINGS']` in `settings.py`
- C) Inside the PostgreSQL schema definition
- D) In Django template tags
**Answer:** B
**Explanation:** `drf-spectacular` exposes the `REDOC_UI_SETTINGS` dictionary in `settings.py` to customize themes, fonts, primary colors, and UI behaviors.

### Q5: Can markdown syntax be used inside `SPECTACULAR_SETTINGS['DESCRIPTION']`?
- A) Yes, Redoc renders markdown including headers, tables, lists, and code blocks
- B) No, only raw unformatted text is permitted
- C) Only XML tags are allowed
- D) Only LaTeX math symbols are supported
**Answer:** A
**Explanation:** `drf-spectacular` and Redoc parse full Markdown in the schema description, enabling rich onboarding guides, tables, and instructions directly at the top of the documentation.
