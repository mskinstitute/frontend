# Redux Toolkit Architecture and Slices

## 1. The Renaissance of Redux with Redux Toolkit (RTK)
Historically, Redux was infamous for overwhelming boilerplate: writing actions, action types, action creators, reducers with manual object spreads, and configuring stores with multiple middleware packages.

In 2019, the Redux team released **Redux Toolkit (RTK)**—the official, opinionated, battery-included standard for modern Redux development.

RTK simplifies Redux by:
- Eliminating manual action creators and action types.
- Incorporating **Immer** under the hood, allowing developers to write "mutating" logic that is automatically converted into safe immutable updates!
- Including `redux-thunk` by default for asynchronous actions.
- Providing `configureStore` with automated DevTools and middleware setup.

```
Legacy Redux:
ActionTypes ──► ActionCreators ──► Manual Switch Reducer with Object Spread ──► createStore()

Modern Redux Toolkit:
createSlice({ name, initialState, reducers }) ──► configureStore({ reducer })
(Clean, concise, and built-in Immer mutation syntax!)
```

## 3. Creating an RTK Slice (`createSlice`)
A **Slice** bundles a domain's initial state, reducer functions, and generated actions together into a single cohesive module:

```javascript
// src/store/courseSlice.js
import { createSlice } from '@reduxjs/toolkit';

const initialState = {
  enrolledCourses: [],
  selectedTrack: 'all',
  searchQuery: ''
};

export const courseSlice = createSlice({
  name: 'courses',
  initialState,
  reducers: {
    // Immer allows us to write "mutating" syntax safely!
    enrollCourse: (state, action) => {
      const exists = state.enrolledCourses.some(c => c.id === action.payload.id);
      if (!exists) {
        state.enrolledCourses.push(action.payload); // Safe via Immer!
      }
    },
    removeCourse: (state, action) => {
      state.enrolledCourses = state.enrolledCourses.filter(c => c.id !== action.payload);
    },
    setSelectedTrack: (state, action) => {
      state.selectedTrack = action.payload;
    },
    setSearchQuery: (state, action) => {
      state.searchQuery = action.payload;
    }
  }
});

// Automatically generated action creators!
export const { enrollCourse, removeCourse, setSelectedTrack, setSearchQuery } = courseSlice.actions;

// Export reducer for store configuration
export default courseSlice.reducer;
```

## 4. Configuring the Central Store (`configureStore`)
```javascript
// src/store/index.js
import { configureStore } from '@reduxjs/toolkit';
import courseReducer from './courseSlice';

export const store = configureStore({
  reducer: {
    courses: courseReducer
  }
});
```

Wrap your root in `src/main.jsx`:
```jsx
import { Provider } from 'react-redux';
import { store } from './store';

<Provider store={store}>
  <App />
</Provider>
```

## 5. Consuming State with `useSelector` and `useDispatch`
```jsx
import React from 'react';
import { useSelector, useDispatch } from 'react-redux';
import { enrollCourse } from '../store/courseSlice';

export default function CourseCard({ course }) {
  const dispatch = useDispatch();

  // Fine-grained selector: only re-renders if this specific boolean changes!
  const isEnrolled = useSelector((state) =>
    state.courses.enrolledCourses.some(c => c.id === course.id)
  );

  return (
    <div className="card">
      <h4>{course.title}</h4>
      <button
        disabled={isEnrolled}
        onClick={() => dispatch(enrollCourse(course))}
      >
        {isEnrolled ? 'Enrolled ✓' : 'Enroll Now'}
      </button>
    </div>
  );
}
```

## Practice Quiz

### Q1: How does Redux Toolkit (RTK) allow developers to write direct mutations like `state.items.push(item)` safely?
- A) JavaScript changed its memory model
- B) RTK uses the Immer library under the hood, which tracks mutations to a draft proxy and converts them into pure immutable copies
- C) Direct mutations are converted to SQL
- D) It only works on Linux
**Answer:** B
**Explanation:** Redux Toolkit integrates Immer within `createSlice`, intercepting mutations on a Proxy draft and generating an immutable state tree automatically.

### Q2: What is an RTK "Slice"?
- A) A piece of a physical hard drive
- B) A cohesive module generated by `createSlice` that bundles a state slice, reducers, and auto-generated action creators together
- C) A CSS transition effect
- D) An alternative to Vite
**Answer:** B
**Explanation:** `createSlice` packages the initial state, reducer logic, and generated action creators for a specific feature domain into one file.

### Q3: Which hook is used to dispatch actions in React-Redux?
- A) `useAction()`
- B) `useDispatch()`
- C) `useStore()`
- D) `useTrigger()`
**Answer:** B
**Explanation:** `useDispatch()` provides access to the Redux store's dispatch function to trigger actions.

### Q4: Which hook is used to extract data from the Redux store with selector functions?
- A) `useSelect()`
- B) `useSelector()`
- C) `useStoreData()`
- D) `useRedux()`
**Answer:** B
**Explanation:** `useSelector` takes a selector function `(state) => state.subSlice` and subscribes the component to updates for that specific data.

### Q5: What function replaces the legacy `createStore` in modern Redux Toolkit?
- A) `buildStore()`
- B) `configureStore()`
- C) `initRedux()`
- D) `makeStore()`
**Answer:** B
**Explanation:** `configureStore()` is the modern standard function that sets up reducers, default middleware (like thunk), and Redux DevTools automatically.
