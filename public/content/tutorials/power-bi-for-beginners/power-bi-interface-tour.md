# Power BI Interface Tour

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. The 3 Primary Views (Left Navigation Rail)
1. **Report View (Canvas):** Where you drag visuals, build interactive KPI dashboards, and format themes.
2. **Table View (Data):** Displays raw rows and columns of tables loaded into memory.
3. **Model View:** The Entity-Relationship diagram showing tables, relationships, cardinality, and filter directions.

---

## 2. The Right-Hand Tool Panes
- **Data Pane:** Displays all loaded tables and their respective fields (columns, calculated columns, measures).
- **Visualizations Pane:** Palette of available visual types (Bar, Line, Pie, Map, Matrix) and formatting settings.
- **Filters Pane:** Apply filters across:
  - Filters on this visual
  - Filters on this page
  - Filters on all pages

# Multiple Choice Questions

### 1. Where in the Power BI Desktop interface do you select which chart type (e.g. Bar, Treemap, Donut) to draw on the canvas?
A. Visualizations Pane
B. File Menu
C. Status Bar
D. Windows Taskbar
**Answer:** A
**Explanation:** The Visualizations pane houses visual icons, field wells (X-axis, Y-axis, Legend), and format properties.
---

### 2. In the Data Pane, what icon distinguishes a calculated measure from a standard table column?
A. A small calculator icon
B. A Greek letter
C. An exclamation mark
D. A dollar sign
**Answer:** A
**Explanation:** Power BI marks DAX calculated measures with a small calculator symbol next to their name.
---

### 3. Which filter scope filters every single visual on every report page simultaneously?
A. Filters on all pages
B. Filters on this visual
C. Filters on this page
D. Cross-filter only
**Answer:** A
**Explanation:** The 'Filters on all pages' bucket applies a uniform slicer condition across every tab in the report.
---

### 4. What happens when you drag a column from the Data Pane directly onto the blank Report canvas?
A. Power BI automatically generates a default visual (usually a table, bar chart, or card) based on the column's datatype
B. The column is deleted
C. The software crashes
D. An error dialog appears
**Answer:** A
**Explanation:** Power BI features automatic visual type inference when fields are dragged onto the canvas.
---

### 5. What ribbon tab contains the 'Transform Data' button that launches the Power Query Editor?
A. Home Ribbon
B. View Ribbon
C. Help Ribbon
D. Modeling Ribbon
**Answer:** A
**Explanation:** The 'Transform Data' button is located in the Queries section of the primary Home ribbon.
