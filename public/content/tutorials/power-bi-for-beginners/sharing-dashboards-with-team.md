# Sharing Dashboards with Team & Power BI Apps

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Distribution Methods in Power BI Service
1. **Direct Sharing:** Share individual report links via email. Good for ad-hoc sharing.
2. **Workspaces:** For BI developers collaborating on report authoring.
3. **Power BI Apps:** The enterprise gold standard. Packages finalized reports and dashboards into a clean, read-only portal for hundreds of end-users.

---

# Multiple Choice Questions

### 1. What is the official enterprise-recommended method for distributing a polished suite of reports to hundreds of business end-users in Power BI?
A. Publish a Power BI App from the Workspace
B. Email `.pbix` files as attachments
C. Put files on a USB drive
D. Print physical paper copies
**Answer:** A
**Explanation:** Power BI Apps package multiple reports into a unified, secure, read-only portal for broad organizational distribution.
---

### 2. What workspace role allows members to view and interact with reports, but prevents them from editing or deleting data models?
A. Viewer
B. Admin
C. Member
D. Contributor
**Answer:** A
**Explanation:** The Viewer role provides strictly read-only access to report consumers.
---

### 3. What is a 'Power BI Dashboard' in the Cloud Service compared to a 'Report'?
A. A single-page canvas created by pinning visual tiles from one or multiple different reports
B. A PowerPoint slide
C. An Excel macro
D. The desktop application
**Answer:** A
**Explanation:** In Power BI Service terminology, a Dashboard is a single high-level canvas that pins tiles from multiple reports.
---

### 4. What license tier is required for a user to view a shared report hosted in a standard Pro workspace?
A. Power BI Pro (or Premium Per User) license
B. Free license
C. Windows 95 license
D. No license required
**Answer:** A
**Explanation:** Sharing content in standard workspaces requires both creator and consumer to hold Power BI Pro licenses (unless backed by Premium Capacity).
---

### 5. How can users set up automated email alerts when a critical KPI (e.g. Sales) breaches a target threshold?
A. Set an alert on a pinned card visual tile in a Power BI Dashboard
B. Write a Python script
C. Call Microsoft support
D. It cannot be automated
**Answer:** A
**Explanation:** Pinned card tiles support automated threshold alerts that send email or Teams notifications when metrics exceed targets.
