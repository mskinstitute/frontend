# Power BI Desktop vs Service

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Comparing Desktop vs Cloud Service
- **Power BI Desktop:** A free Windows application installed locally. Used by **Data Analysts & Developers** to connect to data, model relationships, write DAX measures, and design multi-page reports.
- **Power BI Service:** A cloud-based SaaS platform (app.powerbi.com). Used by **Business Users & Executives** to view dashboards, share workspace apps, configure scheduled refreshes, and set up Row-Level Security (RLS).

---

## 2. Comparison Matrix

| Capability | Power BI Desktop | Power BI Service (Cloud) |
| :--- | :--- | :--- |
| **Primary Role** | Report Authoring & Modeling | Report Sharing & Distribution |
| **Power Query ETL** | Yes (Full Power Query Editor) | Limited (Dataflows) |
| **Data Modeling & DAX** | Full capability | Very limited |
| **Scheduled Refresh** | No (Local file) | Yes (Automated with Gateway) |
| **Target Audience** | Analysts & BI Developers | Management & End Users |

# Multiple Choice Questions

### 1. Where do data analysts build relationships, calculate DAX measures, and design multi-tab reports?
A. Power BI Desktop
B. Power BI Mobile
C. Microsoft Word
D. Windows Media Player
**Answer:** A
**Explanation:** Power BI Desktop is the authoring workstation where data models, DAX formulas, and canvas visuals are constructed.
---

### 2. Which component of Power BI enables automated scheduled data refreshes and executive workspace sharing?
A. Power BI Service (Cloud SaaS)
B. Power BI Desktop
C. Notepad
D. Task Manager
**Answer:** A
**Explanation:** Power BI Service hosts deployed semantic models in the cloud, managing enterprise security, workspaces, and refresh schedules.
---

### 3. Can you view interactive Power BI dashboards on smartphones?
A. Yes, via native Power BI Mobile apps for iOS and Android
B. No, only on Windows desktops
C. Only if exported as JPEG
D. Only via SMS
**Answer:** A
**Explanation:** Microsoft provides responsive mobile apps that format reports specifically for phone screens.
---

### 4. What software is required to connect Power BI Service in the cloud to an on-premises local SQL Server database?
A. On-Premises Data Gateway
B. USB Cable
C. Google Drive
D. TeamViewer
**Answer:** A
**Explanation:** The Microsoft On-Premises Data Gateway acts as a secure bridge, allowing cloud reports to refresh from local corporate databases.
---

### 5. What file extension is used when saving a report in Power BI Desktop?
A. `.pbix`
B. `.pbi`
C. `.xlsx`
D. `.dax`
**Answer:** A
**Explanation:** Power BI Desktop project workbooks are saved with the proprietary `.pbix` extension.
