# Capstone Project: Apply Filters, Slicers, and KPIs

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Assembling the Final Interactive Experience
The final phase of the Capstone project connects all elements:
1. **Interactive Date Range:** Top horizontal slider bound to `Calendar[Date]`.
2. **Category & Regional Slicers:** Dropdowns configured with single-select or multi-select.
3. **Cross-Filtering Validation:** Verify that clicking any category bar dynamically updates all KPI cards.
4. **Reset All Filters Button:** Add an action button bound to an empty bookmark that clears all selections with a single click.

# Multiple Choice Questions

### 1. How do you implement a 'Reset All Filters' button in Power BI?
A. Create an action button and link it to a Bookmark that was captured with all slicers in their cleared state
B. Write a macro
C. Reinstall the app
D. Disconnect the database
**Answer:** A
**Explanation:** Bookmarks capture filter states; assigning a cleared bookmark to a button creates a 1-click filter reset.
