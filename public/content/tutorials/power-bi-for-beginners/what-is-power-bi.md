## 1. Introduction to Microsoft Power BI
**Microsoft Power BI** is a suite of business analytics software, services, and connectors that turn unrelated sources of data into coherent, visually immersive, and interactive insights.

In simple Indian business terminology:
> *Agar aapki company me data alag-alag jagah bikhra hua hai—kuch data Excel sheets me, kuch Tally me, kuch SQL database me—to Power BI in sabhi sources ko ek jagah connect karke live executive dashboard banata hai jise mobile ya web par live monitor kiya ja sakta hai.*

---

## 2. The Power BI Technology Stack
Power BI unifies three legacy enterprise Microsoft engines into a single desktop application:
1. **Power Query:** The Data Extraction & Transformation (ETL) engine.
2. **Power Pivot:** The in-memory columnar database (VertiPaq) and relational modeling engine.
3. **Power View / Power Map:** The interactive data visualization and geospatial rendering engine.

# Multiple Choice Questions

### 1. What are the three primary components that make up the Power BI ecosystem?
A. Power BI Desktop, Power BI Service (Cloud), and Power BI Mobile
B. Word, Excel, and PowerPoint
C. Python, R, and SQL
D. Windows, Mac, and Linux
**Answer:** A
**Explanation:** Power BI operates across Desktop (authoring), Cloud Service (sharing & governance), and Mobile apps (consumption).
---

### 2. Which underlying in-memory database engine powers Power BI's blazing-fast analytical calculations?
A. VertiPaq engine
B. MySQL
C. SQLite
D. MongoDB
**Answer:** A
**Explanation:** VertiPaq is Microsoft's proprietary in-memory columnar compression engine that drives Power Pivot and Analysis Services.
---

### 3. Which part of Power BI is responsible for extracting, cleaning, and transforming raw data before it reaches the data model?
A. Power Query Editor
B. DAX Studio
C. Excel Viewer
D. Report Canvas
**Answer:** A
**Explanation:** Power Query (using the M formula language) handles data ingestion and ETL transformations.
---

### 4. Is Power BI Desktop free to install and use on Windows PCs?
A. Yes, Power BI Desktop is completely free for individual authors
B. No, it costs ₹10,000 per month
C. Only for students with an .edu email
D. Only for 30 days
**Answer:** A
**Explanation:** Microsoft provides Power BI Desktop as a free downloadable tool for report creation and modeling.
---

### 5. What is the primary difference between a static PDF report and an interactive Power BI report?
A. Power BI reports allow cross-filtering (clicking a bar in one chart filters all other visuals dynamically)
B. PDFs can have videos
C. Power BI reports cannot be printed
D. PDFs run faster on servers
**Answer:** A
**Explanation:** Power BI visuals are interconnected; clicking on an element dynamically slices and cross-filters all related visuals on the canvas.
