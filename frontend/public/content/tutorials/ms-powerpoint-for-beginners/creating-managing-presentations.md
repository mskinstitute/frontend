# Creating, Opening, Saving & Backstage View

Managing presentation files efficiently—choosing between blank presentations, curated design templates, modern cloud autosave, and standard file formats—is fundamental to every successful PowerPoint workflow.

---

## The Backstage View (File Menu)

Clicking the orange/red **File** tab at the top-left of the PowerPoint window replaces the editing canvas with the **Backstage View**. This centralized hub handles file-level operations rather than individual slide content:
- **Home**: Quick jump to new blank presentations, featured corporate templates, and recently opened presentations.
- **New**: Browse thousands of searchable Microsoft templates categorized by business, education, pitch decks, infographics, and certifications.
- **Open (`Ctrl + O`)**: Access local files, OneDrive cloud drives, SharePoint sites, or browse your PC storage.
- **Info**: Inspect presentation properties, check compatibility, inspect for hidden sensitive metadata or private notes, and protect with passwords.
- **Save & Save As (`Ctrl + S` / `F12`)**: Save to cloud or local disks.
- **Print (`Ctrl + P`)**: Print full slides, handouts (3 slides per page with lined notes, 6 slides per page, etc.), or speaker notes.
- **Share**: Collaborate with colleagues via cloud share links with specific view or edit permissions.
- **Export**: Create PDF/XPS documents, export high-definition MP4 video, create animated GIFs, or generate Microsoft Word handouts.
- **Options**: Configure auto-recovery duration, default fonts, spelling preferences, and keyboard customization.

## PowerPoint File Formats Explained

Selecting the correct file extension prevents compatibility errors:

| Extension | Format Name | Best Used For |
| :--- | :--- | :--- |
| **.pptx** | PowerPoint Presentation | Standard modern XML format (Office 2007–365). Default choice. |
| **.ppsx** | PowerPoint Show | Opens immediately in full-screen presentation mode on click, bypassing the editor. |
| **.potx** | PowerPoint Template | Master layout template used as a starting blueprint for future decks. |
| **.pptm** | PowerPoint Macro-Enabled | Required if the presentation contains automated VBA macros. |
| **.pdf** | Portable Document Format | Universal read-only format for emailing clients or printing without font issues. |
| **.mp4** | MPEG-4 Video | Exported movie containing all slide timings, voiceover narration, and media. |

## Step-by-Step: Creating and Saving Your First Deck

### Creating from a Professional Template
1. Click **File > New**.
2. Type a topic keyword in the search bar (e.g., `Business Pitch`, `Technology`, or `Education`).
3. Click on a template thumbnail to view a live preview modal showing color palettes and sample slides.
4. Click **Create**. PowerPoint downloads the asset package and builds your starter deck.

### Saving to Cloud vs. Local PC
- **OneDrive / SharePoint (Recommended)**: When saved to Microsoft cloud storage, **AutoSave** activates automatically at the top-left corner. Every keystroke and edit is saved instantaneously, and complete version history is maintained.
- **Local Hard Drive**: Press **F12** to summon the traditional **Save As** dialog box. Choose your destination directory and confirm the `.pptx` file name.

### Recovering Unsaved Work
If PowerPoint closes unexpectedly during a power outage or crash:
1. Reopen PowerPoint. The **Document Recovery** task pane automatically appears on the left with timestamps.
2. If it does not appear, go to **File > Info > Manage Presentation > Recover Unsaved Presentations**.
3. PowerPoint opens the temporary cache folder (`%LocalAppData%\Microsoft\Office\UnsavedFiles`) where auto-saved drafts are preserved.

# Multiple Choice Questions

### 1. Which file format immediately opens in full-screen presentation mode when double-clicked, bypassing the editor?
A. .pptx
B. .ppsx
C. .potx
D. .pptm
**Answer:** B
**Explanation:** The .ppsx (PowerPoint Show) format launches directly into full-screen presentation view, making it ideal for kiosks or sending final presentations to clients.

---

### 2. Which key opens the traditional "Save As" dialog box in PowerPoint with a single press?
A. F12
B. F5
C. Ctrl + S
D. Alt + S
**Answer:** A
**Explanation:** Pressing F12 directly triggers the Save As dialog window, allowing you to choose a new destination path or change file format without navigating menus.

---

### 3. What happens when you save a presentation directly to Microsoft OneDrive or SharePoint?
A. PowerPoint locks the presentation so no one else can read it
B. AutoSave activates, saving edits in real-time and enabling version history
C. All animations and video clips are permanently deleted
D. The file is converted into a read-only PDF
**Answer:** B
**Explanation:** Cloud-saved presentations in Microsoft 365 activate the AutoSave switch, continuously persisting edits and unlocking real-time collaboration.

---

### 4. Which Backstage section lets you check for hidden personal data, inspect accessibility, and password-protect a presentation?
A. File > New
B. File > Info
C. File > Account
D. File > Export
**Answer:** B
**Explanation:** File > Info contains the "Protect Presentation", "Inspect Presentation", and "Manage Presentation" administrative security tools.

---

### 5. If PowerPoint abruptly terminates before you can save your new slides, where can you retrieve auto-recovered drafts?
A. File > Info > Manage Presentation > Recover Unsaved Presentations
B. Insert > Shapes > Unsaved
C. View > Slide Sorter > Trash
D. Design > Variants > Backup
**Answer:** A
**Explanation:** Navigating to File > Info > Manage Presentation > Recover Unsaved Presentations opens the local staging folder containing auto-recovered presentations.
