# Presenter View, Dual Monitors, Laser Pointer & Live Pen Annotations

The moment of presentation delivery is where preparation meets execution. PowerPoint's **Presenter View** transforms a multi-monitor or projector setup into a professional command center, letting you view private speaker notes, upcoming slides, and running stopwatches while projecting clean, uninterrupted slides to your audience.

![Presenter View Delivery](/images/tutorials/ms-powerpoint/presenter-view-delivery.svg)

---

## Understanding Presenter View

When your laptop is connected to an external projector, smart TV, or secondary monitor via HDMI, USB-C, or wireless casting (set to Windows **Extend Mode** via **`Win + P`**):
- **Audience Display**: Sees only the crisp, full-screen slide canvas.
- **Presenter Laptop Display**: Displays the complete Presenter View cockpit:
  - Large preview of the **Current Slide**
  - Live running **Timer** and real-world clock
  - Preview thumbnail of the **Next Slide** or upcoming animation build
  - Scrollable **Private Speaker Notes** pane with text size zoom controls
  - Slide gallery thumbnail bar along the bottom for non-linear jumping
  - Live annotation tools (Laser Pointer, Pen, Highlighter)

## Essential Slide Show Keyboard Shortcuts

Memorizing these in-show shortcuts ensures smooth, confident delivery:

| Shortcut | Action Description |
| :--- | :--- |
| **F5** | Start Slide Show from the beginning |
| **Shift + F5** | Start Slide Show from the active slide |
| **Spacebar / Right Arrow / Enter / N** | Advance to next animation or slide |
| **Backspace / Left Arrow / P** | Return to previous animation or slide |
| **B** | Black out the screen (pause audience attention onto you) |
| **W** | White out the screen |
| **Ctrl + L** | Turn mouse into a virtual Red Laser Pointer |
| **Ctrl + P** | Turn mouse into a live drawing Pen |
| **Ctrl + I** | Turn mouse into a Highlighter |
| **Ctrl + A** | Restore mouse to standard Arrow cursor |
| **Ctrl + E** | Switch to Eraser |
| **E** | Erase all live ink drawings on the current slide |
| **[Number] + Enter** | Type a slide number and press Enter to jump directly to that slide! (e.g., `12 + Enter`) |
| **Esc** | Exit Slide Show |

## Live In-Show Annotation Tools

During delivery, highlighting key figures or circling diagram bottlenecks creates interactive engagement:
1. Hover your cursor at the bottom-left corner of the slide to reveal the semi-transparent presentation toolbar (or use shortcuts **`Ctrl + P`** / **`Ctrl + I`**).
2. **Pen / Highlighter**: Draw freehand directly over diagrams or tables in real time.
3. **Ink Color**: Select ink color (e.g., vibrant yellow or red).
4. **Keeping Ink Annotations**: When you press **Esc** to end your slide show, PowerPoint prompts: *"Do you want to keep your ink annotations?"*. Choosing **Keep** converts your live drawings into editable vector ink drawings preserved on the slides for emailing out!

---

## The "B" and "W" Keys: Commanding Room Focus

One of the greatest presentation secrets practiced by keynote speakers:
- When a heated discussion breaks out or you want all 50 attendees looking directly at you rather than reading a complex slide, press **`B`**. The projector immediately turns pitch black.
- When ready to resume the deck, press **`B`** or any arrow key again, and the slide instantly returns!
- Pressing **`W`** turns the screen solid white (great for using your projector as an impromptu dry-erase whiteboard).

# Multiple Choice Questions

### 1. Which single key can a presenter press during a live slide show to immediately blank the screen to solid black and focus audience attention on the speaker?
A. Esc
B. B
C. Spacebar
D. F1
**Answer:** B
**Explanation:** Pressing the "B" key instantly turns the screen black (and pressing "W" turns it white); pressing it again restores the presentation.

---

### 2. Which keyboard shortcut converts your mouse cursor into a virtual red laser pointer during a live slide show?
A. Ctrl + P
B. Ctrl + L
C. Alt + L
D. Shift + L
**Answer:** B
**Explanation:** Pressing Ctrl + L converts the cursor into an illuminated laser pointer dot. Ctrl + P switches to the ink drawing pen.

---

### 3. How can a presenter jump directly to Slide 18 during a live presentation without clicking through all intermediate slides?
A. Press Esc and find it in the folder
B. Type "18" on the numeric keypad and press Enter
C. Hold Ctrl + Shift + 18
D. Reboot the projector
**Answer:** B
**Explanation:** Typing any slide number and pressing Enter instantly jumps the presentation directly to that target slide.

---

### 4. What display mode in Windows (`Win + P`) must be active for PowerPoint to project full-screen slides to an audience while showing Presenter View on the speaker's laptop?
A. Duplicate
B. Extend
C. Second Screen Only
D. PC Screen Only
**Answer:** B
**Explanation:** Windows "Extend" mode treats the projector as a distinct secondary screen, allowing PowerPoint to display Presenter View privately on the primary laptop.

---

### 5. What happens if you choose "Keep" when PowerPoint asks *"Do you want to keep your ink annotations?"* upon ending a slide show?
A. The computer saves a video of your presentation
B. The live pen and highlighter marks are preserved as editable vector drawing objects on the slides
C. The presentation is locked against further edits
D. All slides are printed
**Answer:** B
**Explanation:** Choosing "Keep" preserves all live ink marks as permanent graphic annotations placed on the slide surfaces.
