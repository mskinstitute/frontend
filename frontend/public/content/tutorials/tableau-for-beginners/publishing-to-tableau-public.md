# Publishing to Tableau Public & Creating Portfolios

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Showcasing Your Data Analytics Portfolio
**Tableau Public** is the premier global showcase where data analysts build public portfolios to demonstrate their visual analytics, storytelling, and dashboard design skills to hiring managers.

### Publishing Workflow:
1. Ensure data does not contain sensitive corporate information.
2. Extract your data (`Data > Extract Data`). *Tableau Public requires an extracted data source!*
3. Go to **Server** $	o$ **Tableau Public** $	o$ **Save to Tableau Public As...**
4. Sign in with your free Tableau Public account.
5. Add tags, description, and link the project to your resume and LinkedIn!

# Multiple Choice Questions

### 1. What connection requirement must be met before a workbook can be published to Tableau Public?
A. The data source must be an active Data Extract (`.hyper`)
B. Must be a live SQL Server connection
C. Must be an audio file
D. Must be in CSV only
**Answer:** A
**Explanation:** Tableau Public requires all data to be saved as an extracted snapshot within the packaged workbook.
