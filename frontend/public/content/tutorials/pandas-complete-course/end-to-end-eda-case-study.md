## 1. What is Exploratory Data Analysis (EDA)?
**Exploratory Data Analysis (EDA)** is the scientific process of investigating a new, raw dataset to discover patterns, spot anomalies, test hypotheses, and verify assumptions using summary statistics and graphical representations.

In this capstone lesson, we walk through a complete, production-ready EDA project on an Indian E-Commerce Transactions dataset.

---

## 2. Step-by-Step EDA Implementation

```python
import pandas as pd
import numpy as np

# STEP 1: INGESTION & FIRST LOOK
df = pd.read_csv('ecommerce_orders.csv', parse_dates=['Order_Date'])

print("--- Dataset Shape ---")
print(f"Total Transactions: {df.shape[0]:,}, Total Columns: {df.shape[1]}")

print("\n--- Column Data Types & Non-Null Counts ---")
print(df.info())

print("\n--- Statistical 5-Point Summary ---")
print(df.describe().T)

# STEP 2: DATA CLEANING & AUDITING
# Check missing percentages
null_pct = (df.isna().sum() / len(df)) * 100
print("\n--- Missing Data % ---\n", null_pct[null_pct > 0])

# Impute missing Discount with 0 and drop rows missing Customer_ID
df['Discount_Pct'] = df['Discount_Pct'].fillna(0)
df = df.dropna(subset=['Customer_ID'])

# Remove duplicate orders
df = df.drop_duplicates(subset=['Order_ID'], keep='first')

# STEP 3: FEATURE ENGINEERING
# Net Revenue = (Quantity * Unit_Price) * (1 - Discount_Pct / 100)
df['Gross_Amount'] = df['Quantity'] * df['Unit_Price']
df['Net_Revenue'] = df['Gross_Amount'] * (1 - df['Discount_Pct'] / 100)
df['Order_Month'] = df['Order_Date'].dt.to_period('M')

# STEP 4: BUSINESS INSIGHTS & AGGREGATIONS
# Top 5 Product Categories by Revenue
top_categories = df.groupby('Category', as_index=False).agg(
    Total_Revenue=pd.NamedAgg('Net_Revenue', 'sum'),
    Total_Units=pd.NamedAgg('Quantity', 'sum'),
    Avg_Order_Value=pd.NamedAgg('Net_Revenue', 'mean'),
    Order_Count=pd.NamedAgg('Order_ID', 'count')
).sort_values(by='Total_Revenue', ascending=False)

print("\n--- Top Categories by Revenue ---\n", top_categories)

# Monthly Revenue Trend
monthly_trend = df.groupby('Order_Month')['Net_Revenue'].sum()
print("\n--- Monthly Revenue Trend ---\n", monthly_trend)
```

## 3. The 5 Core Questions Every EDA Must Answer
1. **Data Quality:** Are there missing values, corrupted strings, or duplicate records?
2. **Distributions:** Are numeric features normally distributed or skewed with extreme outliers?
3. **Key Drivers:** Which categories, regions, or customer segments contribute 80% of revenue (Pareto Principle)?
4. **Time Trends:** Is revenue growing month-over-month, and are there seasonal spikes?
5. **Actionable Recommendations:** What strategic business action should executive leadership take based on the findings?

# Multiple Choice Questions

### 1. What is the primary purpose of Exploratory Data Analysis (EDA)?
A. To deploy machine learning models to production servers
B. To explore, clean, summarize, and understand data structure and anomalies before modeling
C. To write unit tests for front-end websites
D. To compress database storage
**Answer:** B
**Explanation:** EDA is the analytical investigation phase where analysts examine data patterns, test hypotheses, and uncover anomalies.
---

### 2. Which method produces a 5-point statistical summary (count, mean, std, min, 25%, 50%, 75%, max) for numeric columns?
A. `df.summary()`
B. `df.describe()`
C. `df.stats()`
D. `df.overview()`
**Answer:** B
**Explanation:** `df.describe()` computes descriptive statistics summarizing the central tendency, dispersion, and shape of a dataset's distribution.
---

### 3. In the Pareto Principle (80/20 rule) applied to sales analytics, what common pattern is frequently observed during EDA?
A. All products generate exactly equal revenue
B. Approximately 80% of total revenue is generated by top 20% of products or customers
C. 80% of rows contain missing data
D. 20% of columns are always dropped
**Answer:** B
**Explanation:** The Pareto Principle states that roughly 80% of outcomes (revenue) come from 20% of causes (top performing products or VIP clients).
---

### 4. Why should you always inspect `df.info()` at the start of any EDA project?
A. It provides total rows, column names, non-null counts, and datatypes, highlighting missing data and incorrect types immediately
B. It automatically saves the file to the cloud
C. It generates colorful charts
D. It restarts the computer
**Answer:** A
**Explanation:** `df.info()` gives a concise summary of column names, non-null counts, and memory usage, identifying data type mismatches right away.

### 5. What is 'Feature Engineering' in a data analysis workflow?
A. Repairing a broken computer motherboard
B. Creating new meaningful columns (like Net Revenue or Order Month) derived from existing raw columns
C. Deleting all text columns
D. Upgrading Python version
**Answer:** B
**Explanation:** Feature engineering involves deriving new metrics and features from raw data to extract deeper business insights.
