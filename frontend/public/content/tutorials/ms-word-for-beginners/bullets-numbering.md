# Bullets & Numbering

## Lists: Bullets, Numbering & Multilevel Structures

Lists break complex information down into digestible, scannable chunks. Microsoft Word provides three distinct types of lists in the **Paragraph** group on the **Home** tab:

![Bullets and Numbering Tools in MS Word](/images/tutorials/ms-word/home-paragraph-formatting.svg)

### The Three List Types

1. **Bulleted Lists**:
   - Used when list items have no chronological or rank hierarchy (features, ingredients, equipment).
   - Standard bullet styles include Solid Circles (●), Open Circles (○), Squares (■), Checkmarks (✔), and Custom Picture icons.
2. **Numbered Lists**:
   - Used when sequence, rank, or step-by-step priority matters (recipes, procedures, rankings).
   - Formats include Arabic numerals (`1, 2, 3`), Roman numerals (`I, II, III`), and Alphabetic sequences (`A, B, C` or `a, b, c`).
3. **Multilevel Lists (Outlines)**:
   - Used for complex nested outlines, legal contracts, and technical specifications (e.g., `1.`, `1.1`, `1.1.1`).

### Creating & Managing Lists Like a Pro

- **Demote / Indent Sub-item**: Press the **Tab** key at the start of an item to push it inward to a sub-level (e.g. from `1.` to `a.`).
- **Promote / Outdent Item**: Press **Shift + Tab** to pull a sub-item back out to a higher level.
- **Exit List**: Press **Enter** twice on an empty list item to immediately stop list formatting and return to normal text.

### Customizing Numbering Sequences

Right-clicking any number in an active list opens powerful contextual options:
- **Restart at 1**: Resets the counter so this item becomes item number 1 (useful when beginning a new exercise in the same chapter).
- **Continue Numbering**: Links this list with the previous numbered list in your document so the sequence continues seamlessly (e.g., from 5 to 6 across an intervening diagram).
- **Set Numbering Value**: Manually set the starting number to any integer.

### Defining Custom Bullets

You are not limited to black dots!
1. Click the downward arrow next to the **Bullets** button on the Home tab.
2. Click **Define New Bullet...** at the bottom.
3. Choose:
   - **Symbol**: Pick from thousands of Wingdings, Webdings, or Unicode icons (e.g., stars, arrows, checkmarks).
   - **Picture**: Upload your company logo or custom icon.
   - **Font**: Change the bullet's color (e.g., bright green checkmarks) without changing the color of your text!

# Multiple Choice Questions

### 1. Which key demotes a list item to a nested sub-bullet level?
A. Enter
B. Tab
C. Space
D. Shift + Tab
**Answer:** B
**Explanation:** Pressing Tab indents the current item into a sub-level; Shift + Tab outdents it back.
---

### 2. How can you immediately terminate an active bulleted or numbered list while typing?
A. Press Esc
B. Press Enter twice
C. Press Backspace three times
D. Restart Word
**Answer:** B
**Explanation:** Pressing Enter on an empty bullet item terminates list mode and returns to normal paragraph text.
---

### 3. Which list type is best suited for legal contracts and multi-tiered technical outlines (e.g. 1.1, 1.1.1)?
A. Bulleted List
B. Numbered List
C. Multilevel List
D. Sorted List
**Answer:** C
**Explanation:** Multilevel Lists support hierarchical sub-headings with outline numbering like 1.1 and 1.1.1.
---

### 4. Which font family is most famous in Word for containing diverse symbols like stars, arrows, and mailboxes?
A. Calibri
B. Wingdings
C. Times New Roman
D. Arial
**Answer:** B
**Explanation:** Wingdings (and Webdings) is the classic Microsoft symbol font used for custom bullet symbols.
---

### 5. If a second list restarts at 1 when you want it to continue from 5, which right-click command resolves this?
A. Continue Numbering
B. Restart at 1
C. Set Numbering Value to 0
D. Format List
**Answer:** A
**Explanation:** Right-clicking the number and choosing "Continue Numbering" links it to the preceding list.
