# Adding Shapes & Icons

## Shapes & Vector Icons

Shapes and icons allow you to construct flowcharts, callout boxes, decorative divider lines, and diagrams directly inside your document without needing external design software.

### Inserting Shapes

1. Navigate to **Insert** tab > **Illustrations** group > click **Shapes**.
2. Categories available:
   - **Lines**: Straight lines, arrows, elbow connectors, freehand scribbles.
   - **Rectangles**: Sharp corners, rounded corners, single-corner snips.
   - **Basic Shapes**: Circles/Ovals, Triangles, Cubes, Hearts, Lightning bolts.
   - **Block Arrows**: 2D/3D arrows in all directions.
   - **Flowchart**: Decision diamonds, process rectangles, input/output parallelograms.
   - **Callouts**: Speech bubbles and thought balloons.
   - **Stars and Banners**: Ribbons, 5-point stars, scrolls.
3. Click on the canvas and **drag** your mouse to draw the shape.
4. *Pro Tip*: Hold down the **Shift** key while dragging to constrain proportions to a **perfect circle**, **perfect square**, or **straight horizontal/vertical line**!

### Adding Text Inside Shapes

You don't need to create a separate text box over a shape:
- Simply click any shape and start typing! The text automatically centers inside the shape.

### Shape Formatting: Fill, Outline & Effects

When a shape is selected, the **Shape Format** tab appears:
- **Shape Fill**: Background color (Solid, Gradient, Texture, or Image fill).
- **Shape Outline**: Border color, weight (e.g., 2.25 pt), and dash style (solid, dashed, dotted).
- **Shape Effects**: Drop shadows, 3D rotation, soft edges, and bevels.

### Z-Order Layering: Aligning & Stacking

When multiple shapes overlap:
- **Bring Forward / Bring to Front**: Moves the selected shape above other shapes.
- **Send Backward / Send to Back**: Moves the selected shape behind other shapes.
- **Grouping Shapes (`Ctrl + G`)**:
  - Hold `Shift` and click multiple shapes to select them together.
  - Right-click > **Group > Group** (or press `Ctrl + G`).
  - They now behave as a single unified object that can be moved, resized, or rotated together!

# Multiple Choice Questions

### 1. Which key should you hold down while drawing a shape to create a perfect circle or square?
A. Ctrl
B. Shift
C. Alt
D. Tab
**Answer:** B
**Explanation:** Holding the Shift key while drawing constrains the geometry to 1:1 aspect ratio (perfect circles/squares).
---

### 2. How do you add text inside a rectangle or oval shape in MS Word?
A. Draw a text box on top of it
B. Simply click the shape and start typing
C. Convert shape to WordArt
D. Right-click and choose Print
**Answer:** B
**Explanation:** In MS Word, shapes natively hold text; simply selecting the shape and typing places text directly inside.
---

### 3. What is the keyboard shortcut to group multiple selected shapes into a single object?
A. Ctrl + G
B. Ctrl + Shift + G
C. Alt + G
D. Ctrl + U
**Answer:** A
**Explanation:** Ctrl + G groups selected shapes into a single compound object.
---

### 4. Which command moves an overlapped shape underneath other shapes behind it?
A. Bring to Front
B. Send to Back
C. Align Bottom
D. Rotate 180
**Answer:** B
**Explanation:** Send to Back (or Send Backward) drops the selected object behind other layers.
---

### 5. Where are vector SVG Icons located on the Microsoft Word Ribbon?
A. Home > Font
B. Insert > Illustrations > Icons
C. Layout > Page Setup
D. View > Show
**Answer:** B
**Explanation:** Insert > Illustrations > Icons gives access to hundreds of scalable vector SVG icons.
