# Track Changes & Comments

## Collaborative Review: Track Changes & Comments

When co-authoring documents with editors, managers, or colleagues, making direct edits without tracking leads to confusion. Word's **Review** tab provides full revision tracking and commenting.

![Track Changes and Reviewing Tools in Word](/images/tutorials/ms-word/track-changes-review.svg)

### 1. Activating Track Changes (`Ctrl + Shift + E`)

- Shortcut: Press **Ctrl + Shift + E** to toggle revision tracking on or off.
- GUI: Go to **Review** tab > click **Track Changes**.
- When Track Changes is active:
  - Any text you **type** is inserted in a distinct author color with an underline.
  - Any text you **delete** is not erased; instead, it is struck through with a red strikethrough line or placed in a margin balloon.
  - Formatting modifications (like changing font to bold) are recorded in the margin.

### 2. Controlling Markup Display Views

On the **Review** tab > **Tracking** group:
- **Simple Markup (Default)**: Shows clean final text with a vertical red line in the left margin indicating edited paragraphs.
- **All Markup**: Displays every deletion, insertion, author color, and comment balloon simultaneously.
- **No Markup**: Previews what the document will look like once all proposed revisions are accepted.
- **Original**: Displays the document in its pristine state before any reviewer made edits.

### 3. Adding & Replying to Comments (`Ctrl + Alt + M`)

1. Highlight the sentence or term you want to discuss.
2. Press **Ctrl + Alt + M** (or click **Review > New Comment**).
3. A comment card appears in the right margin with your author name and timestamp.
4. Colleagues can click **Reply** to build threaded discussion chains, or click **Resolve** once the feedback is addressed.

### 4. Accepting or Rejecting Proposed Edits

Once the review cycle is complete:
1. Use the **Previous** and **Next** buttons in the Changes group to jump between revisions.
2. Click **Accept**:
   - **Accept and Move to Next**: Adopts the change permanently and advances to the next edit.
   - **Accept All Changes**: Finalizes all edits throughout the entire document at once.
3. Click **Reject**:
   - Discards the proposed change and restores the original wording.

# Multiple Choice Questions

### 1. What is the keyboard shortcut to turn Track Changes ON or OFF in Microsoft Word?
A. Ctrl + T
B. Ctrl + Shift + E
C. Alt + Shift + C
D. Ctrl + Alt + T
**Answer:** B
**Explanation:** Ctrl + Shift + E is the universal shortcut to toggle Track Changes on or off.
---

### 2. What is the keyboard shortcut to insert a New Comment on selected text?
A. Ctrl + C
B. Ctrl + Alt + M
C. Alt + C
D. Shift + F2
**Answer:** B
**Explanation:** Ctrl + Alt + M inserts a new comment in the right margin anchored to the selected text.
---

### 3. Which markup display view shows clean final text with a subtle red vertical line marking edited lines?
A. Simple Markup
B. All Markup
C. No Markup
D. Original
**Answer:** A
**Explanation:** Simple Markup provides a clean reading experience while highlighting altered lines with red margin bars.
---

### 4. What happens to deleted text when Track Changes is enabled under All Markup view?
A. It is permanently deleted immediately
B. It appears in color with a strikethrough line
C. It turns invisible
D. It is converted into a footnote
**Answer:** B
**Explanation:** Deleted text remains visible with a strikethrough and author color until accepted or rejected.
---

### 5. Under which Ribbon tab are Track Changes and Comment tools located?
A. Home
B. Insert
C. References
D. Review
**Answer:** D
**Explanation:** The Review tab houses proofing, commenting, and tracking collaboration tools.
