# Table Styles & Design

## Table Design: Aesthetics & Multi-Page Tables

A raw unformatted grid can look sterile and difficult to read. Word's **Table Design** tab offers ready-made style templates with coordinated colors, alternating zebra striping, and professional border rules.

![Table Styles and Design Options in Word](/images/tutorials/ms-word/tables-insert-format.svg)

### Table Style Options Checkboxes

On the left side of the **Table Design** tab, you control which styling rules are activated:
- **Header Row**: Applies bold text and a dark/accent fill color to the first row.
- **Total Row**: Applies double bottom underlines and bold styling to the summary last row.
- **Banded Rows (Zebra Striping)**: Alternates background shading (e.g. white and light blue) on odd/even rows, dramatically improving horizontal readability in wide data sheets.
- **First Column**: Applies special bold formatting to the left-most column (row labels).
- **Last Column**: Emphasizes the right-most column (e.g., Grand Totals).
- **Banded Columns**: Alternates shading vertically across columns.

### Cell Shading & Custom Borders

- **Shading (Paint Bucket icon)**: Allows you to paint individual cells, rows, or columns in custom colors from the Theme Colors or custom RGB/HEX picker.
- **Borders Grid**: Control visibility of individual borders:
  - Bottom Border, Top Border, Left Border, Right Border
  - **No Border**: Makes the grid lines invisible for clean, unboxed alignment (e.g. signature blocks).
  - **Outside Borders / All Borders**: Applies solid outlines.
  - Border Style, Line Weight (e.g. 1/2 pt, 1.5 pt, 3 pt), and Border Color.

### Critical Feature: Repeat Header Rows on Multi-Page Tables

When a table extends across multiple pages, readers on page 2 and page 3 lose track of what each column represents!
Word provides an automated solution:
1. Highlight the header row(s) at the top of your table on page 1.
2. Go to **Layout** tab (under Table Tools) > **Data** group.
3. Click **Repeat Header Rows**.
4. Result: Word automatically duplicates the identical header row at the top of **every single page** the table spans! If rows shift due to edits, the repeated header adjusts dynamically.

# Multiple Choice Questions

### 1. Which feature ensures that table headers automatically appear at the top of every printed page when a table spans across multiple pages?
A. Copy Paste Header
B. Repeat Header Rows
C. Banded Rows
D. Auto Header
**Answer:** B
**Explanation:** Repeat Header Rows automatically duplicates table headers at the top of subsequent pages.
---

### 2. What is the visual effect created by enabling the "Banded Rows" option in Table Design?
A. Bolds all text in the table
B. Alternates background shading between even and odd rows
C. Draws double borders around the table
D. Hides all borders
**Answer:** B
**Explanation:** Banded Rows creates zebra-striping (alternating row background colors) for easier tracking.
---

### 3. How can you hide visible black grid borders in a table while keeping cell alignment intact?
A. Delete the table
B. Choose Borders > No Border
C. Change font color to white
D. Split table
**Answer:** B
**Explanation:** Applying "No Border" hides gridlines on printouts while keeping the cell layout structured.
---

### 4. Under which group on the Table Design tab can you choose ready-made color palettes for tables?
A. Font Styles
B. Table Styles
C. Drawing Tools
D. Cell Formats
**Answer:** B
**Explanation:** The Table Styles gallery contains pre-built themes with matching headers, borders, and fills.
---

### 5. Where on the Ribbon is the "Repeat Header Rows" tool located?
A. Home > Paragraph
B. Table Tools > Layout > Data group
C. Insert > Header
D. References > Index
**Answer:** B
**Explanation:** Repeat Header Rows is located under Table Tools > Layout in the Data group.
