# Clear Formatting & Styles

## Clear Formatting & Quick Styles Gallery

When copying text from web pages, PDF documents, or external emails, unwanted fonts, colors, and weird indents often corrupt your layout. Microsoft Word provides two powerful mechanisms to maintain clean document aesthetics: **Clear Formatting** and **Styles**.

### 1. Stripping Unwanted Formatting

- **Clear All Formatting Button**: Located in the Font group (represented as an `A` with a pink eraser icon `A⌫`). It strips all font families, colors, bolding, and highlights, resetting selected text back to the default **Normal** style.
- **Keyboard Shortcut**:
  - `Ctrl + Space`: Clears all inline **character** formatting (resets font, size, bold, italic).
  - `Ctrl + Q`: Clears all **paragraph** formatting (resets indents, alignment, and custom line spacing back to Normal style defaults).

### 2. Format Painter: Copying Styles in 1 Click

The **Format Painter** (`Home > Clipboard group`) copies formatting from one piece of text and paints it onto another:
1. Select the text that has the formatting you like.
2. **Single Click** the Format Painter icon (or press `Ctrl + Shift + C`): Allows you to paint the style onto a single target selection.
3. **Double Click** the Format Painter icon: Locks the tool active, allowing you to paint the style onto **multiple** non-contiguous paragraphs throughout your document! Press `Esc` when done.
4. **Shortcuts**:
   - Copy Formatting: `Ctrl + Shift + C`
   - Paste Formatting: `Ctrl + Shift + V`

### 3. The Quick Styles Gallery

Styles are pre-defined combinations of font face, size, color, and paragraph spacing saved under a single name:
- **Normal**: The standard base style for all body paragraphs.
- **Heading 1 (`Ctrl + Alt + 1`)**: Top-level chapter and section titles.
- **Heading 2 (`Ctrl + Alt + 2`)**: Major subheadings.
- **Heading 3 (`Ctrl + Alt + 3`)**: Minor sub-sections.
- **Title / Subtitle**: Cover page and introductory headers.

#### Why You Must Always Use Styles
1. **Automatic Table of Contents**: Word generates automatic tables of contents by scanning for text formatted with `Heading 1`, `Heading 2`, and `Heading 3`.
2. **Global Document Updates**: If your manager requests changing all subheadings from Blue to Dark Green, you simply right-click `Heading 2 > Modify`, select Green, and all 50 subheadings across your 200-page document update instantly!
3. **Navigation Pane**: Allows one-click jumping between document sections in the sidebar.

# Multiple Choice Questions

### 1. What is the keyboard shortcut to clear all inline character formatting back to Normal style?
A. Ctrl + Backspace
B. Ctrl + Space
C. Shift + Delete
D. Ctrl + Q
**Answer:** B
**Explanation:** Ctrl + Space clears all character formatting (font, bold, color), resetting to the underlying style defaults.
---

### 2. What is the keyboard shortcut to reset paragraph formatting (indents and spacing) back to default?
A. Ctrl + Q
B. Ctrl + P
C. Ctrl + Shift + N
D. Alt + Q
**Answer:** A
**Explanation:** Ctrl + Q resets paragraph-level overrides, restoring default line spacing and indents.
---

### 3. How can you keep the Format Painter active so you can paint formatting across multiple separate sections?
A. Right-click the icon
B. Double-click the Format Painter icon
C. Hold Ctrl while clicking
D. Press Shift + P
**Answer:** B
**Explanation:** Double-clicking the Format Painter locks it in active mode until you press the Esc key.
---

### 4. What is the keyboard shortcut to copy ONLY formatting without copying the text itself?
A. Ctrl + C
B. Ctrl + Shift + C
C. Alt + C
D. Ctrl + Alt + F
**Answer:** B
**Explanation:** Ctrl + Shift + C copies formatting attributes, and Ctrl + Shift + V applies them to selected text.
---

### 5. Which heading style shortcut applies the Heading 1 format to the current line?
A. Ctrl + 1
B. Ctrl + Alt + 1
C. Alt + Shift + 1
D. Shift + F1
**Answer:** B
**Explanation:** Ctrl + Alt + 1 applies Heading 1, Ctrl + Alt + 2 applies Heading 2, and Ctrl + Alt + 3 applies Heading 3.
