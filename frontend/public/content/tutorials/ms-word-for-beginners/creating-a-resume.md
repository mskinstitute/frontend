# Creating a Resume

## Mini-Project 1: Designing an ATS-Friendly Professional Resume

A resume is your primary marketing document when applying for employment. In this hands-on project, you will build a clean, modern **Two-Column Professional Resume** combining borderless tables, custom heading styles, and tight paragraph spacing.

![Professional Resume Layout Architecture in Word](/images/tutorials/ms-word/resume-template-layout.svg)

### Step 1: Page Setup & Margins
1. Create a new blank document (`Ctrl + N`).
2. Navigate to **Layout > Margins** > select **Narrow** ($0.5\text{ in}$ / $1.27\text{ cm}$ on all sides).
3. Set Paper Size to **A4** (or Letter).

### Step 2: The Header Banner
1. Insert a 1-row, 1-column table or shape for the header.
2. Fill with Navy Blue (`#185ABD`).
3. Type your Name in **20pt Bold White** font (`Calibri` or `Aptos`).
4. Type your contact details: *Phone | Email | LinkedIn | City* in **10pt White/Light Blue**.

### Step 3: Two-Column Table Grid
Instead of using complex text boxes that break ATS (Applicant Tracking Systems), use a table:
1. Insert a table: **2 Columns, 1 Row**.
2. Set Column 1 width to **35%** (Left Sidebar) and Column 2 width to **65%** (Main Body).
3. Select the table > **Table Design > Borders > No Border** (makes the grid structure invisible).

### Step 4: Left Sidebar Content (Skills & Education)
- Apply a subtle light gray background shading (`#F8FAFC`) to Cell 1.
- Add Section Headings in **11pt Bold Navy**:
  - **TECHNICAL SKILLS**: Bulleted list of programming languages, tools, and platforms.
  - **EDUCATION**: Degree, University name, graduation year.
  - **CERTIFICATIONS**: Accredited credentials.

### Step 5: Right Main Content (Experience & Projects)
- **PROFESSIONAL EXPERIENCE**:
  - Job Title (11pt Bold Black)
  - Company & Dates (10pt Muted Gray Italic)
  - Action-oriented bullet points highlighting quantifiable achievements (e.g. *"Boosted site performance by 40%"*).
- **NOTABLE PROJECTS**: Project title, architecture, and live links.

### Step 6: Exporting to PDF
Navigate to **File > Export > Create PDF/XPS**. PDF locks your fonts and alignment so recruiters view the exact layout you intended on all devices!

# Multiple Choice Questions

### 1. Why are borderless tables preferred over floating text boxes when creating ATS-compliant resumes?
A. Text boxes look blurry
B. Applicant Tracking Systems (ATS) can parse table text sequentially without dropping floating content
C. Tables take less storage
D. Word disables text boxes in resumes
**Answer:** B
**Explanation:** Many ATS scanners fail to extract text from floating shapes/text boxes; structured tables parse cleanly.
---

### 2. Which margin preset is recommended for resumes to maximize canvas space while keeping print boundaries safe?
A. Wide (2.0")
B. Narrow (0.5")
C. Normal (1.0")
D. Mirrored
**Answer:** B
**Explanation:** Narrow margins (0.5 inches) maximize usable canvas space to fit achievements on a concise page.
---

### 3. In which file format should you always submit completed resumes to employers?
A. .txt
B. .docx
C. .pdf
D. .rtf
**Answer:** C
**Explanation:** PDF preserves exact formatting, fonts, and borders across all operating systems and devices.
---

### 4. How do you make the underlying structural table grid invisible on the printed resume?
A. Delete the table
B. Select table and set Borders > No Border
C. Change font to white
D. Set table opacity to 0
**Answer:** B
**Explanation:** Applying "No Border" keeps the aligned 2-column layout while hiding black lines from appearing.
---

### 5. What font size range is standard for body text and bullet points in a professional resume?
A. 6pt - 8pt
B. 10pt - 11pt
C. 14pt - 16pt
D. 18pt - 20pt
**Answer:** B
**Explanation:** 10pt to 11pt is the standard size for readable, professional resume body content.
