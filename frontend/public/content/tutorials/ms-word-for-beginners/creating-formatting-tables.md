# Creating & Formatting Tables

## Tables: Organizing Structured Data

Tables provide clean rows and columns for displaying schedules, price lists, comparison matrices, and financial ledgers. When a table is inserted, Microsoft Word automatically reveals two contextual Ribbon tabs: **Table Design** and **Layout**.

![Table Creation and Formatting in Microsoft Word](/images/tutorials/ms-word/tables-insert-format.svg)

### Three Ways to Insert a Table

1. **Quick Grid Selector**:
   - Path: Click **Insert > Table**.
   - Hover your mouse over the visual square grid (e.g. 4 columns by 5 rows) and click.
   - Ideal for standard tables up to $10 \times 8$ cells.
2. **Insert Table Dialog Box**:
   - Path: Click **Insert > Table > Insert Table...**
   - Allows precise numeric input for **Number of columns** (e.g., 14) and **Number of rows** (e.g., 50).
   - AutoFit options:
     - **Fixed column width**: Keeps columns at fixed pixel widths.
     - **AutoFit to contents**: Shrinks/expands column widths to fit cell contents tightly.
     - **AutoFit to window**: Stretches the table across 100% of the margins.
3. **Draw Table**:
   - Path: Click **Insert > Table > Draw Table**.
   - Turns your cursor into a pencil, allowing you to draw custom rectangular cells and diagonal divisions directly on the canvas.

### Navigating & Editing Inside a Table

| Keystroke | Function |
| :--- | :--- |
| **Tab** | Moves cursor to the next cell to the right. |
| **Shift + Tab** | Moves cursor to the previous cell to the left. |
| **Tab in Last Cell** | Automatically inserts a brand-new blank row at the bottom! |
| **Arrow Keys** | Moves one character or one row up/down. |

### Adding & Deleting Rows and Columns

- **Quick Add Button (+)**: Hover your mouse between any two existing rows or columns near the border. A small blue circle with a plus sign (`+`) appears; click it to instantly insert a new row or column.
- **Contextual Ribbon**: Go to **Layout** tab > **Rows & Columns** group:
  - `Insert Above` / `Insert Below`
  - `Insert Left` / `Insert Right`
  - `Delete` dropdown: Delete Cells, Delete Columns, Delete Rows, or Delete Table.

# Multiple Choice Questions

### 1. What happens when you press the Tab key inside the very last cell of a table in Word?
A. The table is deleted
B. A new row is automatically created at the bottom
C. The cursor leaves the table
D. The cell text is indented
**Answer:** B
**Explanation:** Pressing Tab in the final bottom-right cell automatically creates and moves into a new blank row.
---

### 2. Which contextual tabs appear on the Ribbon when your cursor is inside a table?
A. Table Design and Table Layout
B. Format and Draw
C. Review and View
D. Data and Design
**Answer:** A
**Explanation:** Word activates the "Table Design" and "Layout" contextual tabs whenever a table cell is selected.
---

### 3. Which AutoFit setting adjusts table column widths automatically based on the length of text in each cell?
A. AutoFit to Window
B. AutoFit to Contents
C. Fixed Column Width
D. AutoFit to Margins
**Answer:** B
**Explanation:** AutoFit to Contents resizes column widths to snugly match the longest string of text in each column.
---

### 4. What is the keyboard shortcut to move to the PREVIOUS cell in a Word table?
A. Ctrl + Tab
B. Shift + Tab
C. Alt + Left Arrow
D. Backspace
**Answer:** B
**Explanation:** Shift + Tab navigates one cell backward/to the left, while Tab navigates forward.
---

### 5. How can you quickly delete an entire table without using ribbon menus?
A. Select table and press Delete
B. Select table and press Backspace
C. Press Esc twice
D. Press Ctrl + Delete
**Answer:** B
**Explanation:** Selecting the entire table and pressing Backspace deletes the table structure and its contents (pressing Delete only empties cell contents).
