# Installation & Setup

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. System Requirements & Installation Channels
Power BI Desktop is a native 64-bit Windows application requiring:
- Windows 10, 11, or Windows Server.
- Minimum 4 GB RAM (8 GB+ strongly recommended for production models).
- .NET Framework 4.7.2 or later.

### Recommended Installation Source:
Install via the **Microsoft Store** in Windows.
- **Why?** Automatic monthly background updates without needing manual downloads.

---

# Multiple Choice Questions

### 1. What operating system is natively required to run Power BI Desktop?
A. Microsoft Windows
B. macOS (without virtual machine)
C. Ubuntu Linux
D. Android
**Answer:** A
**Explanation:** Power BI Desktop is built natively for 64-bit Windows operating systems.
---

### 2. Why is installing Power BI Desktop via the Microsoft Store preferred over manual MSI download?
A. Microsoft Store automatically updates the software every month with new features
B. It costs less
C. It includes free internet
D. It uses zero disk space
**Answer:** A
**Explanation:** Microsoft updates Power BI Desktop monthly; the Store installation applies updates automatically.
---

### 3. What is the minimum recommended RAM for smooth development in Power BI Desktop?
A. 8 GB or more
B. 512 MB
C. 1 GB
D. 2 GB
**Answer:** A
**Explanation:** While 4 GB is the bare minimum, 8 GB to 16 GB is recommended to handle in-memory VertiPaq datasets comfortably.
---

### 4. Can Power BI Desktop run natively on Apple Mac Silicon (M1/M2/M3)?
A. No native Mac version exists; Mac users must use Parallels, a Windows Virtual Machine, or cloud services
B. Yes, available in the Mac App Store
C. Yes, using Safari
D. Yes, with Apple Keynote
**Answer:** A
**Explanation:** There is no macOS build; Mac developers run it via Windows on Parallels or Azure Virtual Desktops.
---

### 5. Does using Power BI Desktop require an active Microsoft Pro or Premium paid license?
A. No, Power BI Desktop is free to install, model, and build reports locally
B. Yes, ₹1,500/month from day one
C. Yes, requires credit card
D. Only on weekends
**Answer:** A
**Explanation:** Power BI Desktop is completely free for local report authoring; licenses are only required for sharing in Power BI Service.
