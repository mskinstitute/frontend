# Using Themes and Formatting

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Enterprise Report Themes
A professional report adheres strictly to corporate branding guidelines (hex codes, standard fonts, uniform card styles):
- Go to the **View ribbon** $	o$ **Themes**.
- Choose from built-in themes or click **Browse for themes** to load a custom corporate `.json` theme file.

---

## 2. Formatting Standards
- **Backgrounds:** Use clean off-white (`#F8FAFC` or `#F1F5F9`) backgrounds with pure white (`#FFFFFF`) cards for depth.
- **Drop Shadows:** Add subtle border radius (8-12px) and faint shadows to give cards modern UI polish.
- **Titles:** Standardize font sizes: Report Title 18-20pt bold, Card Callout 24-28pt bold, Visual Titles 12-14pt bold.

# Multiple Choice Questions

### 1. In what file format are custom Power BI color palettes and corporate branding themes saved?
A. `.json`
B. `.csv`
C. `.exe`
D. `.png`
**Answer:** A
**Explanation:** Power BI themes are standardized JSON documents defining color hex codes, font families, and visual defaults.
---

### 2. What design technique creates a clean, modern card container appearance on report canvases?
A. Off-white page canvas background with white visual card containers, rounded corners (8-12px), and subtle drop shadows
B. Using bright neon green backgrounds
C. Making everything pure black and red
D. Using 5 different fonts on each card
**Answer:** A
**Explanation:** High contrast between an off-white canvas and pure white rounded containers creates clean visual separation.
---

### 3. Under which ribbon tab can developers customize and save current report themes?
A. View ribbon
B. File ribbon
C. Home ribbon
D. Help ribbon
**Answer:** A
**Explanation:** The View ribbon houses theme galleries, gridline snapping options, and the theme customizer dialog.
---

### 4. What is the purpose of 'Format Painter' in Power BI Desktop?
A. Copies the visual formatting (fonts, colors, borders, shadows) of one chart and applies it to another with one click
B. Paints pictures on the screen
C. Changes screen brightness
D. Edits SQL code
**Answer:** A
**Explanation:** Just like in Excel and PowerPoint, the Format Painter duplicates visual formatting across elements.
---

### 5. Why should corporate reports maintain a standard 3-to-4 color palette rather than using random rainbow colors on every chart?
A. Consistent color semantics (e.g., Primary Blue for Actuals, Orange for Forecasts, Grey for Benchmarks) eliminate visual confusion
B. Rainbow colors use too much electricity
C. Power BI disables printing if there are too many colors
D. Colors slow down the internet
**Answer:** A
**Explanation:** Disciplined color palettes establish clear visual semantics that guide executive comprehension.
