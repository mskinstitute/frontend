# Exporting to PDF & PowerPoint

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Exporting Power BI Reports
Business workflows often require exporting reports for board meetings:
- **Export to PDF:** Captures static snapshot pages.
- **Export to PowerPoint (Live Data):** Embeds fully interactive Power BI visuals directly into PowerPoint slides!
- **Analyze in Excel:** Connects Microsoft Excel directly to the cloud data model via PivotTables.

---

# Multiple Choice Questions

### 1. Which export option allows embedding a live, fully interactive Power BI visual directly inside a Microsoft PowerPoint slide?
A. Embed live data (PowerPoint Power BI Add-in)
B. Static screenshot
C. Print screen
D. Copy image
**Answer:** A
**Explanation:** The Power BI PowerPoint add-in renders live, interactive, sliceable visuals directly inside slide presentations.
---

### 2. What does the 'Analyze in Excel' feature do?
A. Connects Excel directly to the published semantic model in Power BI Service via an OLAP PivotTable connection
B. Copies raw CSV text
C. Deletes the cloud model
D. Converts Power BI into Word
**Answer:** A
**Explanation:** 'Analyze in Excel' allows finance teams to explore Power BI datasets using familiar Excel PivotTables.
---

### 3. When exporting a multi-page report to PDF from Power BI Desktop, what pages are included?
A. All report pages (except hidden pages unless selected)
B. Only the active page
C. Only tables
D. None
**Answer:** A
**Explanation:** Power BI Desktop exports all visible report tabs into a multi-page PDF document.
---

### 4. Can Power BI report pages be scheduled for automated PDF email delivery to executives every Monday morning?
A. Yes, via Power BI Service 'Email Subscriptions'
B. No, someone must click export manually
C. Only with special hardware
D. Only on holidays
**Answer:** A
**Explanation:** Email Subscriptions automate regular delivery of report snapshots and PDF attachments to designated recipients.
---

### 5. What happens to interactive slicers when a report is exported as a static PDF?
A. Slicers become static images reflecting the exact filter state at the time of export
B. Slicers disappear
C. The PDF crashes
D. Slicers remain clickable in Adobe Reader
**Answer:** A
**Explanation:** Static PDFs capture fixed visual snapshots; interactivity is lost in static print exports.
