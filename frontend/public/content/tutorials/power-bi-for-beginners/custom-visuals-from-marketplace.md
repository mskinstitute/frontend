# Custom Visuals from AppSource Marketplace

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Expanding Beyond Native Visuals
While Power BI includes over 30 core visuals, Microsoft's **AppSource Marketplace** provides hundreds of specialized community and enterprise visuals:
- **Gantt Charts:** For project management timelines.
- **Sankey Diagrams:** For customer journey flows and budget allocations.
- **Word Clouds:** For customer feedback analysis.
- **Chiclet Slicers:** Highly styled image buttons.

---

## 2. Certified vs Non-Certified Visuals
- **Microsoft Power BI Certified Visuals:** Have passed rigorous Microsoft security and privacy audits. They **do not transmit data outside the organization** and can be exported to PDF and PowerPoint.

---

# Multiple Choice Questions

### 1. Where can developers download additional custom visual types directly inside Power BI Desktop?
A. AppSource Marketplace (via 'Get more visuals')
B. Windows Update
C. GitHub releases only
D. Python pip
**Answer:** A
**Explanation:** AppSource is Microsoft's certified marketplace for enterprise Power BI visuals.
---

### 2. What does 'Power BI Certified' mean for a marketplace custom visual?
A. The visual has passed Microsoft's security audits, does not send data outside your network, and supports PDF/PowerPoint exports
B. The visual is free
C. The visual is written in C++
D. It only works for administrators
**Answer:** A
**Explanation:** Certified visuals meet Microsoft security, performance, and data protection standards.
---

### 3. Which specialized custom visual is ideal for illustrating energy, budget, or customer drop-off flow pathways between multiple stages?
A. Sankey Diagram
B. Pie Chart
C. Bullet graph
D. Word cloud
**Answer:** A
**Explanation:** Sankey diagrams visualize the flow and proportional distribution of quantities between nodes.
---

### 4. Are custom visuals saved inside the `.pbix` file?
A. Yes, imported custom visuals are embedded into the workbook
B. No, users must re-download them every time
C. Only if paid
D. Stored in Windows registry
**Answer:** A
**Explanation:** Custom visual packages are bundled directly within the `.pbix` file.
---

### 5. What visual tool from Microsoft allows developers to build custom visuals from scratch using TypeScript and D3.js?
A. Power BI Visuals SDK (`pbiviz`)
B. Notepad++
C. Visual Studio Code only
D. Power Query
**Answer:** A
**Explanation:** The `pbiviz` command-line developer tools enable custom visual development using TypeScript and D3.
