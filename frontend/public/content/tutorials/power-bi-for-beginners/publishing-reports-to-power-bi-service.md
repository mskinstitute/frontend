# Publishing Reports to Power BI Service

*Reading Time: 8 Mins* | *Level: Beginner to Advanced*

---

## 1. Publishing from Desktop to Cloud
Once your report is complete, share it with your organization by clicking the **Publish** button on the Home ribbon:
1. Sign in with your corporate/work Microsoft 365 account.
2. Select target **Workspace** (e.g. `Sales Analytics Workspace`).
3. Power BI uploads the `.pbix` file, separating it into two cloud artifacts:
   - **The Semantic Data Model:** Tables, relationships, and DAX measures.
   - **The Report:** The interactive canvas pages.

# Multiple Choice Questions

### 1. What two distinct cloud artifacts are created in a workspace when you publish a `.pbix` file to Power BI Service?
A. A Semantic Data Model (Dataset) and a Report
B. An Excel sheet and a Word document
C. A video and an audio file
D. An email and a calendar invite
**Answer:** A
**Explanation:** Publishing deploys both the underlying semantic data model and the report visual canvas.
---

### 2. Can you publish reports to Power BI Service using a personal email address (like @gmail.com or @yahoo.com)?
A. No, Power BI Service requires an organizational, business, or educational work email domain
B. Yes, any email works
C. Only Yahoo emails
D. Only with a Google account
**Answer:** A
**Explanation:** Microsoft restricts Power BI Service accounts to organizational domains for enterprise security.
---

### 3. What is an 'App Workspace' in Power BI Service?
A. A shared collaborative cloud environment where team members publish, manage, and govern reports and semantic models
B. A smartphone app
C. A Windows desktop folder
D. A video game
**Answer:** A
**Explanation:** Workspaces are cloud collaborative hubs where teams build and distribute BI content.
---

### 4. How can scheduled data refreshes be configured in Power BI Service?
A. In the Dataset settings under 'Scheduled refresh', configure daily or hourly refresh intervals
B. By keeping the desktop computer on forever
C. Sending emails to Microsoft
D. Pressing Ctrl + S repeatedly
**Answer:** A
**Explanation:** Dataset settings allow scheduled cloud refreshes up to 8 times/day (Pro) or 48 times/day (Premium).
---

### 5. What security feature in Power BI restricts data access so regional managers only see data for their specific city?
A. Row-Level Security (RLS)
B. BitLocker
C. Antivirus
D. Canvas password
**Answer:** A
**Explanation:** Row-Level Security (RLS) filters data dynamically based on the user's role and login credentials.
