# Operating Systems for Desktop, Laptop, and Mobile

Operating systems are tailored for the physical form factor and computing capabilities of the host device. A smartphone requires touch-gesture optimizations and battery power efficiency, while a high-end workstation laptop prioritizes multi-monitor support, keyboard shortcuts, and multitasking memory capacity.

---

## 1. Desktop & Laptop Operating Systems

### A. Microsoft Windows (The Global Desktop Standard)
- Developed by **Microsoft Corporation** (founded by Bill Gates and Paul Allen).
- The most widely used desktop OS in the world (over 70% market share in offices, schools, and homes).
- **Evolution of Windows:** Windows 95 $\to$ Windows 98 $\to$ Windows XP $\to$ Windows 7 $\to$ Windows 8 $\to$ Windows 10 $\to$ **Windows 11** (current version).
- **Key Features:** Easy plug-and-play hardware support, widest software compatibility (MS Office, Tally, games), user-friendly GUI.

### B. Linux (The Open Source Powerhouse)
- Created by **Linus Torvalds** in 1991.
- Fully free and open-source operating system.
- Available in various specialized distributions (**Distros**):
  - **Ubuntu:** The most user-friendly desktop Linux distribution.
  - **Linux Mint:** Popular alternative that closely mimics the Windows interface.
  - **Red Hat Enterprise Linux (RHEL) / Debian:** Leading server operating systems powering web servers and cloud infrastructure worldwide.
  - **Kali Linux:** Specialized Linux distribution used by ethical hackers and cyber security professionals.
  - **BOSS Linux:** Customized Linux distribution developed in India by C-DAC.
- **Key Advantages:** Immune to almost all common Windows viruses, completely free, highly customizable, runs smoothly on older hardware.

### C. Apple macOS
- Developed exclusively by **Apple Inc.** for its Mac line of computers (MacBook, iMac, Mac Mini).
- Built on a certified Unix foundation.
- Known for elegant graphic aesthetics, high stability, video editing performance (Final Cut Pro), and seamless integration with iPhone and iPad.

---

## 2. Mobile Operating Systems

### A. Android OS (Google)
- Acquired and developed by Google; open-source based on Linux kernel.
- Powers billions of budget to flagship smartphones manufactured by Samsung, Xiaomi, Realme, Vivo, OnePlus, and Google Pixel.
- Versions named after desserts historically (Cupcake, Donut, Eclair, Froyo, Gingerbread, Honeycomb, Ice Cream Sandwich, Jelly Bean, KitKat, Lollipop, Marshmallow, Nougat, Oreo, Pie) before switching to numbers (Android 10, 11, 12, 13, 14, 15).

### B. Apple iOS
- Proprietary mobile operating system designed exclusively for iPhone.
- Renowned for privacy controls, timely updates for 5-6 years, and strict App Store review guidelines.

# Multiple Choice Questions

### 1. Which company developed the Windows Operating System?
A. Apple Inc.
B. Microsoft Corporation
C. IBM
D. Google
**Answer:** B
**Explanation:** Microsoft Corporation, founded by Bill Gates and Paul Allen in 1975, created the Microsoft Windows operating system family.

---

### 2. Which desktop Linux distribution is known as the most beginner-friendly and widely adopted for personal computing?
A. Arch Linux
B. Ubuntu
C. Slackware
D. Gentoo
**Answer:** B
**Explanation:** Ubuntu, developed by Canonical Ltd. and the open-source community, is recognized globally as the most user-friendly, polished, and beginner-accessible Linux desktop distribution.

---

### 3. What is the default web browser pre-installed with modern Microsoft Windows 10 and 11?
A. Internet Explorer
B. Google Chrome
C. Microsoft Edge
D. Mozilla Firefox
**Answer:** C
**Explanation:** Microsoft Edge (built on the Chromium engine) is the default built-in web browser in modern Windows 10 and Windows 11, replacing the retired Internet Explorer.

---

### 4. Which operating system exclusively powers Apple MacBook and iMac computers?
A. iOS
B. macOS
C. watchOS
D. iPadOS
**Answer:** B
**Explanation:** macOS is the specialized desktop Unix operating system engineered by Apple specifically for Mac desktop and laptop hardware.

---

### 5. What was the historic naming convention for versions of the Android mobile operating system prior to Android 10?
A. Indian Rivers
B. Alphabetical Desserts and Sweets
C. Space Missions
D. Mountain Peaks
**Answer:** B
**Explanation:** Google named Android versions alphabetically after desserts and confectionery sweets (e.g. Cupcake, Donut, Eclair, Froyo, Gingerbread, KitKat, Lollipop, Oreo, Pie).
