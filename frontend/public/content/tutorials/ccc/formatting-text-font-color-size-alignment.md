# Formatting Text: Font, Color, Size, Alignment (टेक्स्ट फ़ॉर्मेटिंग)

**Text Formatting** enhances the visual presentation of a document, making it professional, legible, and visually engaging for readers and government officials.

---

## 1. Character Formatting (Font Properties)

- **Font Name (फॉन्ट):** The visual typeface design of letters.
  - English Standard Fonts: Times New Roman, Arial, Calibri, Liberation Serif (LibreOffice default).
  - Hindi Standard Fonts: **Kruti Dev 010**, **Mangal (Unicode)**, Chanakya.
- **Font Size (फॉन्ट आकार):** Measured in **Points (pt)** ($1 \text{ inch} = 72 \text{ points}$).
  - In LibreOffice Writer, the default font size is **`12 pt`**.
  - Dropdown sizes typically range from **`6 pt` to **`96 pt`**, but you can type custom sizes manually up to **`999.9 pt`**.
- **Font Styles & Shortcuts:**
  - **Bold (मोटा):** **`Ctrl + B`**
  - **Italic (तिरछा):** **`Ctrl + I`**
  - **Underline (रेखांकित):** **`Ctrl + U`**
  - **Double Underline:** **`Ctrl + D`** (In LibreOffice Writer!).
- **Strikethrough:** Draws a horizontal line through the center of text (e.g. ~~~₹500~~~ ₹299).

---

## 2. Superscript and Subscript (सुपरस्क्रिप्ट और सबस्क्रिप्ट)

In scientific, mathematical, and chemical typing:
- **Superscript (सुपरस्क्रिप्ट):** Raises text above the normal baseline in a smaller font (e.g. $X^2$, $10^{\text{th}}$).
  - In LibreOffice Writer: **`Ctrl + Shift + P`** (P = Power).
  - In MS Word: **`Ctrl + Shift + +`**
- **Subscript (सबस्क्रिप्ट):** Lowers text below the normal baseline (e.g. $H_2O$, $CO_2$).
  - In LibreOffice Writer: **`Ctrl + Shift + B`** (B = Base).
  - In MS Word: **`Ctrl + =`**

---

## 3. Paragraph Alignment (पैराग्राफ अलाइनमेंट)

Alignment determines how text lines are arranged between the left and right page margins. There are four standard alignments:

| Alignment | Visual Appearance | Standard Shortcut | Typical Usage |
| :--- | :--- | :--- | :--- |
| **Align Left (बायां)** | Aligned evenly along left margin; jagged right edge | **`Ctrl + L`** | Standard letters, emails, body paragraphs |
| **Align Center (मध्य)** | Centered between left and right margins | **`Ctrl + E`** | Document titles, headings, certificates |
| **Align Right (दायां)** | Aligned evenly along right margin; jagged left edge | **`Ctrl + R`** | Dates, signatures, receipt totals |
| **Justify (समान)** | Aligns text evenly to **BOTH left and right** margins by adjusting word spacing | **`Ctrl + J`** | Newspapers, books, official government gazettes |

---

## 4. Clear Direct Formatting (फ़ॉर्मेटिंग हटाना)

If you copy text from a website that has messy fonts, colors, and backgrounds, you can instantly strip all custom formatting and reset it to default:
- In **LibreOffice Writer:** **`Ctrl + M`**
- In **Microsoft Word:** **`Ctrl + Spacebar`**

# Multiple Choice Questions

### 1. What is the keyboard shortcut for Superscript ($X^2$) in LibreOffice Writer?
A. `Ctrl + Shift + S`
B. `Ctrl + Shift + P`
C. `Ctrl + Shift + B`
D. `Alt + S`
**Answer:** B
**Explanation:** In LibreOffice Writer, `Ctrl + Shift + P` applies Superscript (Power). `Ctrl + Shift + B` applies Subscript (Base).

---

### 2. Which paragraph alignment aligns text smoothly along BOTH the left and right margins simultaneously?
A. Center
B. Justify
C. Left
D. Right
**Answer:** B
**Explanation:** Justify (`Ctrl + J`) expands inter-word spacing so text lines touch both the left and right margins evenly, providing a clean book-like layout.

---

### 3. What is the keyboard shortcut to Center-align text?
A. `Ctrl + C`
B. `Ctrl + E`
C. `Ctrl + A`
D. `Shift + C`
**Answer:** B
**Explanation:** `Ctrl + E` is the universal shortcut to center-align text. (`Ctrl + C` is reserved for Copy).

---

### 4. Which keyboard shortcut applies a "Double Underline" to text in LibreOffice Writer?
A. `Ctrl + U`
B. `Ctrl + Shift + U`
C. `Ctrl + D`
D. `Alt + U`
**Answer:** C
**Explanation:** In LibreOffice Writer, pressing `Ctrl + D` applies a double underline to selected text. (In MS Word, `Ctrl + D` opens the Font dialog).

---

### 5. What is the keyboard shortcut to "Clear Direct Formatting" in LibreOffice Writer?
A. `Ctrl + M`
B. `Ctrl + Spacebar`
C. `Ctrl + Shift + C`
D. `Delete`
**Answer:** A
**Explanation:** In LibreOffice Writer, `Ctrl + M` clears all manual font, size, and color styling, returning text to the default paragraph style.
