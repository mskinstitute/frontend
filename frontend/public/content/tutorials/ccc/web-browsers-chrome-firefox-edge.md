# Web Browsers: Chrome, Firefox, Edge, Opera (वेब ब्राउज़र का परिचय)

A **Web Browser** is an application software used to locate, retrieve, interpret, and display web pages and multimedia content from web servers across the World Wide Web.

Without a web browser, the raw HTML, CSS, and JavaScript codes hosted on internet servers would appear as gibberish text!

---

## 1. Popular Web Browsers

1. **Google Chrome:** The world's most dominant web browser (over 65% global market share). Fast, synchronizes seamlessly with Google accounts, and supports thousands of extensions.
2. **Mozilla Firefox:** Free and open-source browser developed by the non-profit Mozilla Foundation. Known for privacy protections and tracking blockers.
3. **Microsoft Edge:** The default built-in web browser in Windows 10 and 11, re-engineered on Google's open-source Chromium engine.
4. **Apple Safari:** The default web browser optimized exclusively for Apple devices (iPhone, iPad, Mac).
5. **Opera:** Known for built-in free VPN, ad-blocker, and integrated social messaging sidebars.
6. **Tor Browser:** Onion router browser used for extreme privacy and anonymous browsing.

> **First Web Browsers in History (CCC Special):**
> - **WorldWideWeb (Nexus):** The world's first web browser, invented by Tim Berners-Lee in 1990.
> - **Mosaic (1993):** The world's first graphical web browser capable of displaying images and text together on the same page (developed by Marc Andreessen at NCSA).

## 2. Browser Interface Components

- **Address Bar (URL Bar / Omnibox):** The text box at the top where you type website addresses (e.g. `https://www.google.com`).
- **Navigation Buttons:**
  - **Back ($leftarrow$):** Return to previous webpage (**`Alt + $leftarrow$`**).
  - **Forward ($ightarrow$):** Move to next webpage (**`Alt + $ightarrow$`**).
  - **Refresh / Reload ($circlearrowright$):** Reloads active page (**`F5`** or **`Ctrl + R`**).
- **Bookmarks / Favorites (बुकमार्क):** Saves web addresses for quick 1-click access (**`Ctrl + D`**).
- **Browsing History (इतिहास):** Chronological list of previously visited web pages (**`Ctrl + H`**).
- **Downloads Manager:** Displays downloaded files (**`Ctrl + J`**).

---

## 3. Incognito / Private Browsing Mode

When you browse normally, your browser stores **Cookies** (login sessions), search queries, and temporary cache files.

When you use a public cyber cafe or computer lab in Uttar Pradesh, always open **Incognito Mode (Private Window)**:
- **Shortcuts:**
  - In Chrome / Edge: **`Ctrl + Shift + N`**
  - In Firefox: **`Ctrl + Shift + P`**
- **What Incognito Does:** The moment you close the Incognito window, your browsing history, cookies, form auto-fill data, and temporary cache are **completely erased from the computer**!

# Multiple Choice Questions

### 1. What was the name of the first graphical web browser capable of displaying images inline with text?
A. Internet Explorer
B. NCSA Mosaic
C. Google Chrome
D. Opera
**Answer:** B
**Explanation:** NCSA Mosaic, released in 1993 by Marc Andreessen, was the first widely adopted graphical web browser that displayed pictures inline with text.

---

### 2. Which keyboard shortcut bookmarks the currently active webpage in Google Chrome and Microsoft Edge?
A. `Ctrl + B`
B. `Ctrl + D`
C. `Ctrl + Shift + B`
D. `Alt + D`
**Answer:** B
**Explanation:** Pressing `Ctrl + D` in modern web browsers saves the current URL to your Bookmarks/Favorites bar.

---

### 3. What is the keyboard shortcut to open an Incognito (Private) window in Google Chrome?
A. `Ctrl + P`
B. `Ctrl + Shift + N`
C. `Ctrl + N`
D. `Alt + Shift + P`
**Answer:** B
**Explanation:** `Ctrl + Shift + N` opens a new Incognito window in Google Chrome and Microsoft Edge. In Mozilla Firefox, `Ctrl + Shift + P` is used.

---

### 4. Which keyboard shortcut opens the browser's "Downloads" history window?
A. `Ctrl + D`
B. `Ctrl + J`
C. `Ctrl + H`
D. `Ctrl + Shift + D`
**Answer:** B
**Explanation:** In Chrome, Edge, and Firefox, `Ctrl + J` opens the Downloads manager interface. (`Ctrl + H` opens browsing history).

---

### 5. What data is NOT saved by the browser when you browse in Incognito Mode?
A. Downloaded files saved on your hard disk
B. Browsing history, cookies, and temporary site data
C. Your computer monitor model
D. Your internet provider speed
**Answer:** B
**Explanation:** Incognito mode discards browsing history, cookies, session credentials, and temporary cache files immediately upon closing the window.
