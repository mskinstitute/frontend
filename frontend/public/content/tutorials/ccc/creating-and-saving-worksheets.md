# Creating and Saving Worksheets (वर्कशीट बनाना और सुरक्षित करना)

A single LibreOffice Calc or Excel workbook can house multiple related worksheets—for example, a financial year workbook containing 12 monthly sheets (*January, February, March...*).

Managing sheets, renaming them with meaningful labels, and saving data in secure formats are essential skills for office accounting.

---

## 1. Creating and Adding New Worksheets

- **Using the Plus (+) Icon:** Click the `+` button located on the sheet tab bar at the bottom left corner of the screen.
- **Using Menu Bar:** Click **Sheet menu $\implies$ Insert Sheet** (or right-click an existing sheet tab and select **Insert Sheet**).
- **Keyboard Shortcut (Calc):** **`Ctrl + F1`** (or `Shift + F11` in Excel).
- You can choose to insert the new sheet *Before current sheet* or *After current sheet*, and specify how many sheets to add.

---

## 2. Renaming and Organizing Worksheets

By default, sheets are named generically (*Sheet1, Sheet2, Sheet3*). To rename a sheet for clarity:
1. **Double-click** the sheet tab at the bottom.
2. Or right-click the sheet tab and select **Rename Sheet (शीट का नाम बदलें)**.
3. Type a descriptive name (e.g. `Students_Attendance` or `Q1_Sales`) and press **Enter**.

### Color-Coding Sheet Tabs:
To visually organize sheets, right-click any sheet tab $\implies$ select **Tab Color** $\implies$ choose a color (e.g. Green for *Paid*, Red for *Pending*).

### Deleting and Hiding Sheets:
- Right-click the sheet tab $\implies$ choose **Delete Sheet** (Warning: A deleted sheet cannot be restored using Undo!).
- Choose **Hide Sheet** to conceal sensitive calculations from view without deleting them.

---

## 3. Saving the Spreadsheet File

- **Save (`Ctrl + S`):** Saves the workbook in default **`.ods`** format.
- **Save As (`Ctrl + Shift + S` in Calc / `F12` in Excel):** Creates a new copy or allows you to save in another format.

### Saving as Microsoft Excel Format (`.xlsx`):
If you must share your spreadsheet with a client who only has MS Office:
- In Calc, click **File $\implies$ Save As $\implies$ Select file type "Excel 2007–365 (.xlsx)"**. Calc will export a 100% compatible Excel file.

### Protecting Worksheets with Passwords (पासवर्ड सुरक्षा):
To prevent accidental or unauthorized tampering of formulas:
- Click **Tools menu $\implies$ Protect Sheet**.
- Enter a secret password. Once protected, users can view values but cannot edit or delete cells without the password!

# Multiple Choice Questions

### 1. What is the keyboard shortcut to insert a new worksheet in Microsoft Excel?
A. `Ctrl + N`
B. `Shift + F11`
C. `Alt + N`
D. `F12`
**Answer:** B
**Explanation:** In Microsoft Excel, pressing `Shift + F11` immediately inserts a new blank worksheet into the active workbook.

---

### 2. Can a deleted worksheet be recovered using the "Undo" (`Ctrl + Z`) command?
A. Yes, always
B. No, deleting a worksheet is a permanent action that cannot be undone
C. Only if the file is saved as PDF
D. Only in LibreOffice, not in Excel
**Answer:** B
**Explanation:** Deleting a worksheet permanently removes its data and memory structures from the active session. The standard Undo command cannot restore a deleted sheet.

---

### 3. Which menu in LibreOffice Calc provides options to Protect a Sheet with a password?
A. File Menu
B. Tools Menu
C. Format Menu
D. View Menu
**Answer:** B
**Explanation:** In LibreOffice Calc, sheet security and password protection are configured under the **Tools** menu ("Tools > Protect Sheet").

---

### 4. How can you quickly rename a worksheet tab at the bottom of the screen?
A. Double-click the sheet tab
B. Press `Ctrl + Shift + R`
C. Delete the sheet and create a new one
D. Close the application
**Answer:** A
**Explanation:** Double-clicking the sheet tab opens the "Rename Sheet" dialog box directly, allowing you to enter a new name.

---

### 5. What is the native file extension of spreadsheets saved in Microsoft Excel?
A. `.ods`
B. `.xlsx`
C. `.odt`
D. `.docx`
**Answer:** B
**Explanation:** Modern Microsoft Excel workbooks (Excel 2007 and newer) use the Office Open XML format with the `.xlsx` extension.
