# Using Search Engines and Surfing Websites (सर्च इंजन और वेबसाइट सर्फिंग)

With over 2 billion websites on the World Wide Web, finding specific information—such as a government job notification, syllabus PDF, or train schedule—would be impossible without an automated index.

A **Search Engine** is a specialized web-based software system designed to search, index, and retrieve information stored on the World Wide Web according to queries entered by users.

---

## 1. Popular Search Engines

- **Google (गुगल):** The world's most dominant search engine (founded in 1998 by Larry Page and Sergey Brin). Handles over 90% of global searches.
- **Microsoft Bing:** Search engine integrated into Windows 10/11 and Microsoft Edge.
- **Yahoo! Search:** One of the early pioneers of web searching and portal directories.
- **DuckDuckGo:** Privacy-focused search engine that **does NOT track user searches** or build personal advertising profiles.
- **Baidu:** Leading search engine in China.
- **Yandex:** Leading search engine in Russia.

---

## 2. How Search Engines Work (The 3 Core Stages)

```text
   [The Entire Web] ──► 1. CRAWLING (क्रॉलिंग) ──► 2. INDEXING (इंडेक्सिंग) ──► 3. RANKING (रैंकिंग)
                         Bots / Spiders scan        Categorizes text into       Displays best results
                         billions of pages          giant databases             matching your query
```

1. **Crawling (Web Spiders / Bots):** Automated software programs (called *Spiders* or *Crawlers*) continuously traverse the web, following hyperlinks from page to page, discovering new content.
2. **Indexing:** The search engine reads and analyzes the text, images, and keywords on discovered pages, storing them in vast centralized database indexes.
3. **Ranking & Serving Results:** When you type a query (e.g. *"CCC exam admit card 2026"*), complex algorithms evaluate hundreds of factors (page relevance, domain authority, speed) and return the best matching search results on the **SERP (Search Engine Results Page)** in fractions of a second!

---

## 3. Advanced Google Search Operators (Smart Search Tips)

To find exact exam notices without wading through promotional spam:

- **Quotes (`"..."`):** Search for the exact word sequence.
  - *Example:* `"NIELIT CCC exam dates"` returns only pages containing that exact phrase.
- **Site Operator (`site:`):** Restricts searches to a specific website domain.
  - *Example:* `CCC syllabus site:nielit.gov.in` searches only inside the official government portal!
- **Filetype Operator (`filetype:`):** Searches strictly for downloadable file formats.
  - *Example:* `computer fundamentals filetype:pdf` returns directly downloadable PDF notes!
- **Minus Sign (`-`):** Excludes unwanted words from results.
  - *Example:* `jaguar speed -car` searches for the animal, filtering out car models.

# Multiple Choice Questions

### 1. Who are the co-founders of Google Search Engine?
A. Bill Gates and Paul Allen
B. Larry Page and Sergey Brin
C. Steve Jobs and Steve Wozniak
D. Mark Zuckerberg and Eduardo Saverin
**Answer:** B
**Explanation:** Google was founded in September 1998 by Stanford PhD students Larry Page and Sergey Brin.

---

### 2. What are the automated software programs used by search engines to discover and scan web pages called?
A. Browsers
B. Spiders / Crawlers
C. Compilers
D. Firewalls
**Answer:** B
**Explanation:** Search engines deploy automated programs termed Web Crawlers, Spiders, or Bots to systematically browse the internet and index web content.

---

### 3. Which Google search operator restricts results strictly to a specific file format (e.g. finding only PDF files)?
A. `format:`
B. `filetype:`
C. `doc:`
D. `download:`
**Answer:** B
**Explanation:** The `filetype:` operator (e.g. `filetype:pdf` or `filetype:xlsx`) limits Google search queries exclusively to matching file extensions.

---

### 4. Which of the following search engines is renowned for protecting user privacy by NOT tracking search history?
A. Bing
B. DuckDuckGo
C. Yahoo!
D. Google
**Answer:** B
**Explanation:** DuckDuckGo is a privacy-centric search engine that does not record search queries, track IP addresses, or build user profiles for targeted advertising.

---

### 5. What does the acronym "SERP" stand for in search engine terminology?
A. System Electronic Route Protocol
B. Search Engine Results Page
C. Standard Encrypted Response Packet
D. Secure External Resource Portal
**Answer:** B
**Explanation:** SERP stands for Search Engine Results Page, which refers to the list of organic links, featured snippets, and ads returned by a search engine in response to a keyword query.
