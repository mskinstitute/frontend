# Compare & Combine Documents

## Comparing & Combining Documents: Legal Blacklining

In legal, publishing, and contract negotiation environments, clients or colleagues often return documents where they made changes **without turning on Track Changes**. Finding every modified word across a 60-page agreement manually is virtually impossible.

Microsoft Word features a dedicated **Legal Blackline Comparison Engine** that compares two versions of a file and highlights every single addition, deletion, and formatting difference.

### 1. Comparing Two Versions of a Document

1. Open Microsoft Word (a blank window is fine).
2. Go to **Review** tab > **Compare** group > click **Compare > Compare...**
3. In the Compare Documents dialog box:
   - **Original document**: Browse and select the original baseline file (e.g. `Contract_v1.0.docx`).
   - **Revised document**: Browse and select the modified returned file (e.g. `Contract_v1.1_ClientEdits.docx`).
   - Click **More >>** to customize comparison rules (compare Moves, Comments, Formatting, Case changes).
   - Under *Show changes in*, select **New document**.
4. Click **OK**.

### 2. The 3-Pane Comparison Workspace

Word launches a specialized 3-way split screen:
1. **Left (Revisions Pane)**: A chronological itemized list of every single insertion and deletion with exact timestamps.
2. **Center (Compared Document)**: The master redlined document showing all differences in bold markup colors.
3. **Right (Source Documents)**: Divided vertically into two panes showing the *Original Document* on top and the *Revised Document* below, scrolling synchronously!

### 3. Combining Revisions from Multiple People

If you emailed a report draft to three managers (HR, Finance, and Legal) and each person emailed back their own separate edited file:
- Do NOT merge them by hand!
- Go to **Review > Compare > Combine...**
- Combine Manager 1 with the Original, then combine Manager 2's file into the result.
- Word compiles all three reviewers' edits into a **single unified master document**, color-coding each manager in their own unique author color!

# Multiple Choice Questions

### 1. What tool allows you to find every difference between an original file and an edited file if Track Changes was NOT turned on?
A. Find and Replace
B. Review > Compare Documents
C. Word Count
D. Document Inspector
**Answer:** B
**Explanation:** Review > Compare analyzes two versions of a document and generates a legal blackline comparison markup.
---

### 2. What is the function of the "Combine" tool in Microsoft Word?
A. Merges multiple Word files into a ZIP archive
B. Consolidates revisions from multiple separate reviewers into a single master document
C. Combines tables into an Excel sheet
D. Joins headers and footers
**Answer:** B
**Explanation:** The Combine feature consolidates edits from multiple reviewers into a single document with unique author colors.
---

### 3. In the Compare Documents workspace, how do the Original and Revised source panes on the right scroll?
A. They must be scrolled independently by hand
B. They scroll synchronously in tandem with the center compared document
C. They do not scroll
D. They only zoom
**Answer:** B
**Explanation:** The source panes scroll synchronously with the comparison canvas, providing immediate before/after context.
---

### 4. Where should you choose to output the comparison results so original files remain untouched?
A. Over original file
B. Over revised file
C. New document
D. Printer
**Answer:** C
**Explanation:** Choosing "Show changes in: New document" protects both source files from being overwritten.
---

### 5. Under which Ribbon tab is the Compare and Combine toolset found?
A. Home
B. View
C. Review
D. References
**Answer:** C
**Explanation:** Compare is situated in the Review tab alongside proofing and tracking tools.
